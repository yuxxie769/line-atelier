# Line Atelier · v4 线稿研究

从 v4 提交 `67e63ed4e020a7bbec6714e3b4767d89c70c53dc` 恢复工作台并改进。v5 仅作为流程和图层理念参考。保留 v4 的 Canvas 笔刷、按长度逐笔回放、鼠标／触笔输入、工程文件、参考图与 WebMCP。

本轮新增原尺寸局部复核、稳定笔迹 ID、单笔替换／删除／插入、部位分组、轻量显隐撤销、图层缓存。模型绘画界面和 WebMCP 已移除自动描边、颜色分区与差值补色入口。旧算法文件保留在 v4 源码历史中作对照，当前 app 不导入它们。

`dist/lineart-study.line.json` 是通过浏览器 WebMCP 分批绘制和修正的纯线稿。`studies/lineart-batches.json` 保存原始提交批次；最后生效的轨迹及修订原因以工程文件为准。结构稿在清线开始时自动隐藏。未开始上色，不声称已经达到参考视频的美术水平。

本轮覆盖八阶段流程的第一阶段。后续顺序：头发大色块、皮肤底色、服装大色块、配饰／鞋履底色、覆盖阴影、高光与整理、局部复核。部位与深度排序独立于绘制阶段。

## Development

静态入口为 `dist/index.html`。现有 Vite 配置仅用于开发预览。`npm test`；`node scripts/build-standalone.mjs` 生成可离线打开的 HTML。

16 项模型和引擎检查覆盖原有回放、压力透明度、稳定 ID、局部修订、失败原子性、缓存显隐及草稿自动隐藏。实际浏览器本轮示例：显隐前后 drawUnits 均为 24848，合成约 1.2 / 2.7 ms（本次环境的一次测量，不代表所有设备）。
