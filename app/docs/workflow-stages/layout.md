# 1A 整体定位

本阶段结束、推进到 1B 前，执行程序返回的 `stage.agentReview`：子 agent 初审一次，修订后新开子 agent 最终复核一次。既检查人体构造方法，也检查实际形体关系；按“零明确 major、允许 minor”的容差决定，不新增逐笔许可。完整说明见 [子 agent 阶段复核](../workflow-actions/agent-review.md)。

按参考图建立整幅画布的位置、比例、姿态、重心和负形。先明确头、胸廓、骨盆、四肢、关节和脚的体块；不以鞋或衣物外轮廓代替人体。

进入本阶段后，先通过 `paint_get_reference_card` 完整读取必读的 CSP-01 与 CSP-05，之后才能提交或修改笔迹。该工具固定返回整章和全部说明图；CSP-00 可用于补足起稿入口，CSP-07 可用于复杂姿势，但都不能替代必读卡。卡片只作为构造与绘画指导，人物姿态、比例和设计仍以本次目标参考图为准。

保留定位底稿，检查各部分属于同一姿态。局部完成后退回整体对照；位置或比例偏差应修正，不能留给清线掩盖。

## 提交之后必须校准

初次定位也按每批 1–3 笔推进，一批只建立一个关系，例如头胸方向、肩胯倾斜或一条肢体链。提交成功仅表示笔迹已执行，底稿仍是待校准的初稿。先完成播放并提交当前整图对照检查，再继续下一批；检查头身比例、头／胸廓／骨盆的位置和倾斜、肩胯方向、关节位置、四肢端点、重心及身体周围的负形。

发现偏差，直接修正已有定位底稿或锚点，再返回整图对照；不要在错误占位上继续堆衣物和细节。确认定位接近参考后才进入 1B；1C 的集中修稿不能替代这里的即时校准。不要求每次必须改一笔，也不以修改次数判定完成。

1A 的提交、修改和状态结果通过 `localFeedback.layoutCalibration` 持续返回整图对照入口、当前定位笔迹 ID、本版本涉及的定位笔迹 ID 及所引用的锚点 ID。优先执行 `localFeedback.next` 中的整图校准提示。图像已返回时仍需实际判断，程序不会把它标为“已校准”。这一过程属于起稿本身，不增加正式审核轮次或逐笔审批。

1A 整图对照后调用 `paint_record_inspection`，target 使用 `whole`；按返回 criteria 分别比较比例、姿态与负形。未提交当前画面的完整对照记录，或仍有未解决问题时，程序拒绝推进到 1B。仅返回图片不算完成，所有项确实接近参考可记录 aligned，无需为了通过虚构偏差。
