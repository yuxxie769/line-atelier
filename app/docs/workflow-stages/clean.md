# 1E 独立清线

依据参考和细化草稿选择、修正、重画正式线条，不能把全部草稿直接描深，也不能因为是重新落笔就默认形体正确。

进入本阶段后，先通过 `paint_get_reference_card` 完整读取必读的 CSP-08，之后才能提交或修改笔迹。该工具固定返回整章和全部说明图；若发现比例或关节问题，返回相应草稿阶段并读取该阶段必读章节，不能在清线阶段用顺滑掩盖结构错误。卡片只作为构造与绘画指导，人物姿态、比例和设计仍以本次目标参考图为准。

## 清稿通用循环

这套规则对脸、手、头发、衣服、鞋和任何其他部位相同：

1. 用 `basis.guideIds` 绑定当前部位已经确认的底稿。
2. 清 1–3 笔；程序不允许这批线脱离同部位底稿。
3. 同时看参考、底稿和当前清稿，只记录 `preserved`（保留）、`improved`（改善）或 `regressed`（退步）。前两者可以继续；退步时只能修当前部位，修后再检查。

五项造型检查只在阶段出口使用，不进入每个小批次。程序保证底稿绑定、检查顺序、图片版本和退步后的操作范围；视觉结论是否真实仍由执行绘画的模型负责。

主轮廓、内部结构与细节应有轻重区别；清除重复试探线、误线、毛刺及无意义碎线。保留必要转折，平滑不能替代形体判断。

可见轮廓连续，线端接到明确位置或止于真实遮挡。领缘、袖口、鞋口的边界位置与厚度须围绕对应人体体块。每个部位清线后对照参考并退回整图；发现结构问题返回相应阶段修正。保留草稿和独立清线版本，随后进入 1F。

先理解细化稿中每组线承担的轮廓、体积或遮挡作用，再选择正式线条。继承有效经过点与方向依据，删去试探线；发现错误时依据参考修稿后重画，不机械描深，也不忽略底稿重新估形。

先用 `paint_inspect_context` 读取该局部目标、相关底稿和未解决问题。若关键转折、宽窄、开口或遮挡起止还需要大幅猜形，返回细化处理，再继续清线。已经确认的形状不因追求顺滑而随意改变。

开始清线前承接 1D 的五项结果验收与推荐轮廓；旧版“通过”记录不能代替当前形体判断。清线主要处理选线、笔触和轻重，不把尚未解决的体积、受力或前后关系留到正式线中重新估形。

每组清线都执行上面的三步。删除结构线前确认其作用已由其他线表达，或确属无用试探线；线条减少本身不是改善。需要改变底稿形状时，以参考为依据回到局部细化，确认新底稿后再清线。主轮廓、遮挡边与内部提示线的轻重须服务于体积，不能只机械套用统一线宽。

普通批次只提交 1–3 条有联系的正式线。与其他绘画阶段相同，同属一个部位、两端开放且不承担敏感结构关系的低风险线，可用 `batchMode:"low-risk-clean"` 一批提交 5–6 条；五官、手脚、关节、接头、遮挡和关键转折仍保持 1–3 条。笔长服从参考中的曲率变化，不把多个凸起、收缩或转向压成均匀长弧。完成播放后只按 `drawingCycle.pendingTargets` 复看本批实际改动目标；整图与未改部位在阶段节点按 `stagePending` 统一检查。发现偏差先返修、复看并解决问题。

正式线可以由少量相互接续的笔迹共同形成一条视觉连续的轮廓。复杂轮廓必须通过 `paint_submit.compoundGroups` 或 `paint_revise.compoundReplace` 提交完整源路径、1–2 个结构抬笔点和全局压力计划，由程序生成 2–3 条带短搭接的实际笔迹；不能直接手写最终 `compoundId`。普通单线只用于确实能一气呵成的简单扫线，并须填写 `contourMode:"simple-sweep"` 与具体理由。主要受力处、转面处和遮挡根部按参考设置局部压力，不能只依赖统一的三段 taper；程序检测到“长而复杂”的普通路径会拒绝提交。完整字段和接笔规则见状态返回的 `drawingProtocol.compoundMethod`。
