# 1B 完整粗稿

在人体占位上组织衣物、头发、配饰和鞋履，建立主要体块、轮廓、前后关系与连接。衣袖包住手臂，鞋包住脚；理解遮挡后方的结构如何延续。

进入本阶段后，先通过 `paint_get_reference_card` 完整读取必读的 CSP-02、CSP-03 与 CSP-04，之后才能提交或修改笔迹；它们分别提供简单体块、上半身连接和下半身距离链。该工具固定返回整章和全部说明图；CSP-07 可在复杂遮挡时补充，但不能替代必读卡。卡片只作为构造与绘画指导，人物姿态、比例和设计仍以本次目标参考图为准。

保留可追溯的部位底稿。粗稿可以试探，但不能用“轮廓已经画出”代替体积与透视判断；对照整图检查主要部位是否遗漏。

每批只画 1–3 笔并解决一个轮廓或连接关系。落笔前从参考找出起止、凸起、收缩、转向、接线和遮挡位置；长线必须保留实际曲率变化，不能用均匀弧线或三角折线概括整个肢体、发束或衣片。每批后只对照并记录本批实际改动部位；整图与未改部位留到阶段节点。发现偏差先返修、复看并解决问题，再画其他部位。

粗稿中的多短线应共同探索同一条有依据的曲线族，而不是在轮廓附近随机抖动。复杂曲面可在宽窄极值、关节转折、遮挡和受力变化处分笔，让前一笔略过目标转折、后一笔从已确认的方向接入；重叠只保留能说明方向的部分。若几笔已共同承担一个轮廓意图，用同一 `compoundId` 记录它们，避免后续细化把它们误当成互不相关的碎线。
