# 1D 细化草稿

从大形收敛到具体结构，细化五官、手指、发束、衣褶、领缘、配饰和鞋履。以参考图确定厚度、开口、连接与叠层，不用规则几何形状替代尚未理解的细节。

进入本阶段后，先通过 `paint_get_reference_card` 完整读取必读的 CSP-08，之后才能提交或修改笔迹。该工具固定返回整章和全部说明图；CSP-08 只处理结构成立后的线条质量，不允许借细化重新猜测整体比例。卡片只作为构造与绘画指导，人物姿态、比例和设计仍以本次目标参考图为准。

首次进入 1D 后，先取得当前整图的参考／草稿对照，用 `paint_record_refinement_diagnosis` 记录整图诊断：参考中可见的事实、结构判断、当前草稿事实、不确定处，以及 `proceed`（可以分部位细化）、`return-structure`（退回结构修订）或 `needs-evidence`（补看）的结论。没有本次运行生成且结论为 `proceed` 的整图诊断，程序拒绝 1D 落笔。

对照参考确认底稿的目标形状；底稿有误先修稿。衣褶和发丝可以开放，主要物体边界仍应成立。保留细化草稿，复看实际结果及整体关系，不确定项标为待核实。

承接结构修订后的底稿：沿用已经确认的位置、方向、比例、体积和遮挡关系，在此基础上补足内部结构与细节。发现底稿偏差先修正，再继续细化；不能仅因细节落笔而重新猜测整体位置。

按几条相互关联的边界推进，不一次概括整个复杂部位。例如脚部先确定脚踝收缩、脚跟突出、足背到前掌的宽度变化，再处理脚底到脚尖；这些边界始终在同一局部对照里判断。根据参考选择关键转折、宽窄极值和相邻空隙，把依据落到底稿的经过点或已有锚点，不能只记“这是脚／领结／衣褶”。

复杂处按结构分组反复修正，每批限 1–3 笔并只处理一个轮廓或连接关系；平缓轮廓可较快推进，但长线仍须保留参考中的凸起、收缩和转向。每组后读取工具返回的 `localFeedback`，只检查 `drawingCycle.pendingTargets` 中本批实际改变的部位，指出具体哪段过宽、过窄、转弯过早或遮挡位置不对；整图和最终部位检查放在进入 1E 前的结果验收。发现偏差先修相关笔迹、复看并解决问题，再继续其他部位。

细化稿应把“试探线簇”收敛为可供清线选择的复合轮廓，而不是直接变成一条贯穿整个部位的数学曲线。凡轮廓跨越曲率极值、转面、遮挡起止或线条职责变化，必须通过 `paint_submit.compoundGroups` 或 `paint_revise.compoundReplace` 提交完整源路径、1–2 个结构抬笔点和全局 `pressureProfile`，由程序生成 2–3 条带短搭接的实际笔迹。普通单线只用于简单扫线，并须填写 `contourMode:"simple-sweep"` 与具体理由；不得直接手写最终 `compoundId`。完整规则由 `drawingProtocol.compoundMethod` 注入。

持续问题通过既有 `paint_update_issue` 保存 `description`（当前偏差）、可选 `target`（参考中要恢复的具体形状）和 `guideIds`（实际底稿）。目标应落实为可比较的形状关系，而非“更自然、更精细”。先确定轮廓、内部结构、遮挡起止和角色特征，再把该局部交给清线；不确定处保留为问题。

## 局部细化的标准流程

本流程同时适用于首次细化和清线后的局部回退。回退前保存当前版本；保留已经成立的整体定位和无关部位，仅修有明确依据的局部。若问题涉及整体比例或关节，返回相应结构阶段。

它不是仅在返修时触发。整图诊断允许继续后，每个部位第一次细化、同一部位上一批修改完成复看后继续画，以及从清线退回 1D 处理形体歧义时，都先做一次局部诊断。局部诊断通过当前原尺寸对照图绑定精确 `target`，分别写出参考事实、结构推断、当前草稿事实和不确定处，再选择：`detail`（形状基本成立，补结构）、`repair`（已有明确偏差，先修）、`retain`（已经足够，保持不改）或 `needs-evidence`（补看）。只有 `detail`／`repair` 返回可用于一个小批次的 `diagnosisId`。

1. **诊断并建立参考目标。** 同时观察参考、当前草稿和整图，先逐项记录看见了什么，再说明结构推断，最后才产生修改目标。把目标与实际底稿 ID、区域和精确 `target` 关联。例如，先记录“参考袖外轮廓在肘外侧达到宽度极值，肘弯内侧出现数条汇聚短褶；草稿外轮廓是一条均匀弧线，内侧没有汇聚关系”，才能推断并写出“肘外侧鼓起、内侧压缩，主要褶皱汇向肘弯”。看不清处选择 `needs-evidence`，不能凭空补细节。
2. **主轮廓与大体积。** 暂时隐藏试探线和表面细节，检查轮廓、宽窄、方向、厚度及负形。允许保留必要的体块辅助线，不能要求只凭外轮廓表达所有体积。大体积未成立，不继续堆叠细节。
3. **必要结构。** 补足支持转面、关节、受力或叠压的线。手先确定掌块、拇指与弯曲指组；衣褶先明确受力、压缩和垂落；头发先确定主要发束宽窄、厚度与前后；鞋口先确定围绕脚踝的截面。这些是按参考选用的检查方式，不要求画出参考中不可见的结构。
4. **角色细节与选线依据。** 再展开五官、发丝、衣缘、配饰、鞋带等。每条准备交给清线的线应有明确用途：外轮廓、遮挡边、内部结构／转面或表面细节。不要求逐笔填写表格，但主体须有一套明确的推荐轮廓；试探方案留在辅助层，不能把互相矛盾的几套形状交给清线猜选。
5. **修改前后对照。** 修改前保留该局部的实际画布图和版本；每批修改后，对照“参考 → 修改前草稿 → 修改后草稿”，说明原偏差、具体改变、形体改善及相邻影响。未改善或出现退步，先返修；若原形已经成立，可保持不改，不强制凑修改次数。“更顺滑、更干净、接上了”不能单独作为形体改善的证据。

程序把一次局部 `detail`／`repair` 诊断只授权给一个当前画面和一个精确目标。`paint_submit`、`paint_revise`、几何编辑、平滑、线宽／压感和场景结构修改在 1D 都要携带该 `diagnosisId`；受影响笔迹的 `part` 或 `objectId` 必须与诊断目标一致。完成这一批后，画面版本变化使旧诊断失效；必须先完成修改后图像检查，再基于新画面重新诊断，才能继续落笔。`retain`／`needs-evidence` 不授权修改。

程序能核验阶段顺序、当前图片 ID、区域覆盖、必填事实、结论枚举、目标匹配、单批授权失效、修改后检查和阶段退出五项是否齐全。程序不能识别“袖外侧是否真的鼓起”、结构推断是否正确、动作目标是否美观，也不能阻止模型用貌似具体但不真实的文字敷衍；这些仍由实际视觉比较负责。因此，程序通过只证明执行链完整，不证明细化质量达标。

修改前图片仅作历史比较，不能作为当前版本通过的凭据。程序在可用的完整播放状态下自动保存修改前渲染状态；修改后的 `paint_observe_review` / `paint_inspect_context` 返回同区域、同尺度的 `beforeAfter`，其中 `drawing` 是修改前画布，正常 `drawing` 或上下文图仍为当前画布。`status:available` 时，`paint_record_inspection` 必须填写 `changeSummary`，说明具体改善／退步及相邻影响。恢复工程、参考改变或没有修改前快照时明确返回 unavailable，不能声称做过前后对照；先重新建立当前观察再修改。快照仅在当前运行保留，返回的图片进入调用证据日志，不自动成为工程底图。

每项保存 `reference`、`drawing`、`conclusion` 和有效的当前 `observationIds`。可逐项指定图片 ID，省略时沿用本次共享 ID 并由程序展开保存；旧图、假 ID、不覆盖目标的图片不能作为当前通过依据。细化阶段不增加子 agent 或正式审核轮次。

## 进入清线的结果验收

局部完成后退回整图；进入 1E 前，查看当前细化稿的整图、缩小图、镜像及必要局部，并完成以下五项。辅助线可隐藏以判断推荐轮廓是否独立成立；改变可见图层后须重新取得当前检查图。

| 验收项 | 必须在草稿中实际可见的结果 | 程序检查项 |
| --- | --- | --- |
| 临摹一致性 | 姿态、主要比例、标志性轮廓和可见神态符合参考；合理修形没有改掉核心设计 | likeness |
| 体积成立 | 推荐轮廓与必要结构线能说明方向、厚度和转面，不靠试探线堆叠掩盖尚未确定的形状 | volume |
| 边界成立 | 主要物体归属明确，连接与遮挡起止有依据；开放衣褶与发丝不机械闭合 | boundary |
| 细节充分 | 当前任务要求的手指、发束、衣褶、开口等已有可直接沿用的具体形状，不能只画成可辨认的符号 | detail |
| 整体协调 | 局部放回整图后比例、负形、疏密和曲率协调，缩小或镜像不暴露整体退步 | coherence |

1D、1E、1F 的五项必须分开提交；缺项、重复项或沿用旧的三项格式会被程序拒绝。不能用同一段泛化结论替代所有部位。互不抵消，不计算平均分；细节充分按参考风格和用户范围判断，不按笔数、线密度或逐像素一致判断。`localFeedback.inspection.targets` 返回每个目标的状态：pass、needs-work、needs-evidence、stale 或 needs-inspection。相关几何、显示或参考变化使已通过记录失效；旧记录保留作审计，不作为导入或恢复后的通过授权。程序验证材料与填写完整性，不验证模型陈述的美术事实。

- **通过**：五项均达到本阶段要求，剩余差异不影响形体、特征与清线依据；保存细化检查点，进入 1E。
- **待修**：有具体结果未达到，登记部位、参考依据和修改目标，回到对应步骤。不能把“没有发现明显错误”当作五项已成立。
- **证据不足**：关键部位还看不清或推荐轮廓尚不明确，补充对照后再判断，不转录为通过。

多个轻微偏差若共同造成明显的体积流失、角色特征弱化或整体僵硬，须说明可定位的共同影响并返修；不能拆成互不阻断的 minor 后放行。轻微差异也不能仅因数量多而自动升级。

1D 的交付物是保留的细化版本、明确的推荐轮廓、当前图像绑定的五项结果记录，以及剩余差异／问题。清线时若仍需决定掌指关系、发束前后、衣褶受力或鞋口截面，说明相关局部尚未完成细化。
