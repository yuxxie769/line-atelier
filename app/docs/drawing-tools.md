# Line Atelier v4：清线工具与分辨率

> 正式作画与质量标准统一维护在仓库 `docs/WORKFLOW_PRINCIPLES.md`，网页同源正文见 [workflow-principles.md](workflow-principles.md)。本文保留工具用法与历史背景；其中的原则摘要不单独维护。当前 R3 接口见 [agent-guide.md](agent-guide.md)，下文旧工程状态不代表当前 R3。

更新：2026-09-05。基于 v4 开发；v5 只参考流程和区域叠层理念。

本轮新增三项实际能力：主动缺口扫描与画布标注、区域泄漏预览、压感曲线与局部线宽编辑。新画布默认 1200 × 1600，PNG 默认 2× 几何重绘。当前示例仍为原来的 717 条结构修订记录，未重新绘制人体，未开始上色，也未改变 needs-work 结论。

## 1. 绘画原则与工具的职责

模型依据参考理解人体、物体、体积、透视和遮挡，自行选择经过点、线条走向、压力和修订方式。程序执行曲线插值、渲染与检查。参考线稿提取只供视觉观察，不自动变为画布路径、选区或色块。

优先保证结构成立，其次是造型美观与参考特征一致，再提高线条位置的精确度。人体先于服装细节建立；物体边界须清楚。不了解物品名称时，以原图的可见轮廓、体积、开口和连接方式为依据，不凭空增加设计。

“闭合”指物体边界可理解、应相接处连续，并非把每根衣褶、发丝都闭成环。遮挡后的轮廓可以不画；前后关系必须合理。算法报告不是结构正确或艺术质量合格的证明。

每个局部从大形到细节，完成后回看相邻物体、全身画布和全身参考。两轮正式审核统一在 1F 进行；前期边画边检查不另计轮次：

| 轮次 | 检查重点 | 工具辅助 |
| --- | --- | --- |
| 1F 第一轮：结构与造型 | 人体、关节、体积、透视、遮挡、开口，以及比例、轮廓美感、负形、整体协调和参考特征 | 局部与全身对照、缩小图、同步翻转、共享几何与遮挡关系 |
| 1F 第二轮：清线质量 | 边界、接头、重线、残线、线条轻重 | 主动缺口扫描、区域泄漏预览、压力和线宽编辑 |

两轮都应完成实际观察，不是数满即通过。修改后重新检查受影响局部及全身；任何明显结构错误、物体边界缺失或错误遮挡未解决，都不能进入上色。完整粗稿之后仍须独立细化和清线。程序本轮没有增加自动艺术评分，也不伪造两轮观察记录。

## 2. 主动缺口扫描

绘画面板顶部的“线稿检查”可选择精细清线、细化草稿、粗稿或所有笔迹，默认检查当前可见清线。先显示完成作品。扫描全图，或当前物体及其子物体；相邻物体仍作为连接候选。

- 洋红色：附近存在可能相接的线，标出疑似缺口和候选连接方向。
- 琥珀色：开放端点或很短的笔迹，需模型判断是否合理。
- 点击列表中的疑点，打开对应区域与原图对照。
- 搜索距离 1–40 个文档像素，方向容差 0–180°；采用实际笔宽估计可见间隔。
- 即使端点标记为 open，或没有声明接头，仍主动检查；不再只检查模型声明应相接的端点。

扫描基于保留的线条几何及当前可见墨迹，过滤隐藏层、遮挡和已擦掉的端点。小距离同向近邻只是候选，不能认定必须相接。开放发丝、衣褶、刻意留白可能被提示。算法不理解人体，也不能保证定位每个内部擦除缺口；区域泄漏检查用于补充验证。

原有 `paint_check_connections` 保留，用于核对已声明接头。新的扫描不会自动吸附、补线、修改工程或批准线稿。

## 3. 区域泄漏预览

展开“区域泄漏预览”，点击“在画布上选择区域”，再点物体内部；这次点击只取检查点，不落笔。也可填写文档 X、Y 坐标。

- 橙色：选中区域可以连通到画布边缘。如果原本预期为封闭物体，应检查缺口。
- 青色：当前不透明度阈值和检查分辨率下，该区域封闭；仍需判断边界是否属于正确物体。
- 点击在线上：提示换一个区域内部点。

检查使用真实可见线稿的 alpha，默认阈值 24/255。颜色底色、参考图、纸张背景不作为线条屏障；不可见选区的轮廓不会变成封口线。现有擦除、图层透明度、剪贴与场景遮挡参与结果。图层显隐与已有场景遮挡独立：隐藏前景线层不会自动取消该物体遮挡关系。

WebMCP 可额外指定最多 16 个比较点，返回是否与种子同属一个连通区域，可区分“袖子内部”“衣外背景”等模型已理解的位置。不进行自动区域语义识别。

采用四邻域连通。检查图默认使用文档分辨率，最长边不超过 2048；细线、抗锯齿和透明度阈值会影响连通结果。检查自身不做膨胀或虚拟补口。整个背景本来就开放，不能把背景连通直接当作错误。

## 4. 标注与结果有效性

标注是独立覆盖层，可以显示、隐藏、清除，不进入 PNG 和笔迹 JSON。修改画布、图层可见性／透明度或播放位置后，旧结果自动清除，必须重新检查。切换检查子阶段也清除旧结果。

模型通过 `paint_get_diagnostics` 读取结果；`includeImage:true` 可取得带标注的局部 PNG，最长边最多 2048。普通绘画截图始终不含检查标注和参考图。

扫描和泄漏预览会更新页面检查状态，但不写入笔迹历史或改变参考图。应先 `paint_playback({action:"finish"})`；检查工具不会悄悄移动时间轴。

## 5. 压感与整条线的提按

在“压感与局部线宽”面板设置：

- 压感响应：线性、轻笔细重笔粗、轻压即加粗，或自定义节点。
- 最小笔宽：轻压时相对基础笔宽的下限，可低至 0。
- 沿线提按：节点为 `[沿可见线长的位置, 压力]`，两者均为 0–1。包含位置 0、1，可添加中间节点，最多 64 个；位置严格递增。
- 试笔预览：即时显示当前设置。已有笔迹可读取当前压力，再应用修改。

`pressureCurve` 将输入压力映射为响应；`pressureProfile` 则指定沿整条线的压力。两者不是同一个参数。没有 pressureProfile 时使用原始点压力；有它时覆盖压力分布，但保留原始曲线和原始压力，设为 null 可恢复。

触笔使用 PointerEvent 的真实压力。鼠标没有真实压力输入，默认恒压；启用沿线提按后，可模拟模型明确指定的变化。WebMCP 模型直接提交压力值，不依赖模拟鼠标按压力度。

示例：

```json
{
  "pressureFloor": 0.03,
  "pressureCurve": [[0,0],[0.5,0.25],[1,1]],
  "pressureProfile": [[0,0.1],[0.2,0.8],[0.55,0.4],[0.8,0.9],[1,0]]
}
```

外轮廓、内部结构、发丝与遮挡边缘应由模型按其作用决定轻重，不应给全部线条套用同一种压力模板。原示例没有因此被自动重加压力或重新绘制。

## 6. 局部线宽编辑

选中笔迹，给出沿线起终点百分比、倍率和边缘过渡范围。例如中间 30%–60% 加粗到 1.5 倍，前后各用 5% 线长渐变。

程序保留中心线路径、原始压力及响应曲线，将局部倍率作为独立可保存的修改记录。区间和过渡以外的线宽不变；不会通过重新拟合曲线来改变形体。可累计最多 32 次局部线宽修正，批量编辑最多 50 条笔迹，整个操作原子验证、可撤销。只重画受影响图层，关联质量复核失效。

压力修改和局部倍率修改需分开调用。过渡范围为线长的 0.1%–50%，倍率 0.1–4；累计最大笔宽不能超过 180 个文档像素。

## 7. 更大的画布和高分辨率输出

新画布默认从 800 × 1000 提高到 **1200 × 1600**；手动新建和 `paint_new_document` 默认一致。单边最大 2048，保持现有多层缓存的内存边界。

PNG 导出可选 1×、2×、3×，默认 2×；最长边不超过 4096，超过限制的选项禁用。导出按保留的曲线在目标分辨率重新采样、渲染，不是把现有 PNG 拉伸。

- 当前参考工程维持 586 × 1248 的作画坐标；默认 2× 输出 **1172 × 2496**。
- 新建默认画布 1200 × 1600，默认 2× 输出 **2400 × 3200**。
- 局部复核已有 1×–4× 几何重绘，继续可用。

网页“适应”缩放只改变显示尺寸，不等于改变作品分辨率。提高输出分辨率不会自动增加缺失细节、修好人体或提升原参考的清晰度。只有采样点的旧笔迹按已有折线重绘，不能恢复丢失的曲线控制信息。

## 8. WebMCP 调用顺序

1. 读取 `paint_get_state`、`paint_get_scene`，确认图层、阶段与坐标。
2. `paint_playback({action:"finish"})` 显示全部笔迹。
3. `paint_scan_gaps({maxGap:10,angle:65,limit:120,subphases:["clean"]})`。
4. `paint_preview_leak({seed:[x,y],targets:[[outsideX,outsideY]],threshold:24})`。
5. `paint_get_diagnostics({includeImage:true,region:[x,y,w,h],scale:2})` 查看带标注局部；另看原图和全身。
6. 用 `paint_revise` 修形或补线；用 `paint_edit_pressure` 修改轻重。
7. 修改后重新检查，记录实际观察，不把工具返回成功当作线稿通过。

局部线宽示例：

```json
{
  "ids": ["existing-stroke-id"],
  "range": [0.3,0.6],
  "factor": 1.5,
  "feather": 0.05,
  "note": "加强这个接触边缘的中段，保留两端轻线和原有形状"
}
```

新增工具为 `paint_scan_gaps`、`paint_preview_leak`、`paint_get_diagnostics`、`paint_clear_diagnostics`、`paint_edit_pressure`。页面 JSON 面板同步支持 scan_gaps、preview_leak、edit_pressure、clear_diagnostics action。

## 9. 性能与验证

缺口检索使用空间网格，避免所有端点与所有线段全量比较。检查图按画布修订、图层状态和子阶段缓存；纯线稿层优先复用现有绘制缓存，混合内容才重新渲染线稿。不在每帧重新扫描或填充。

验证覆盖主动开放端点扫描、T 接头、闭环、遮挡、单像素泄漏、alpha 阈值、真实 Canvas 擦除与剪贴、无形区域不代替线稿封口、压力导入导出、局部线宽不改路径、撤销和回放。测试成功只说明这些程序行为成立，不证明当前示例达到商业线稿质量。

## 一次查看部位底稿与定位依据

开始一个部位前，优先调用 `paint_inspect_context({query:"左眼"})`，或使用明确的 `objectId` / `[x,y,w,h]` 的 `region`。它把原本分开的观察和坐标查询合并，不检查绘画是否合格，也不拦截下笔。

返回内容：对应参考局部、当前画布局部、隐藏底稿的独立图和叠图、标出范围的整幅图；笔迹名称、稳定 ID、图层、意图、原始几何、解析后的整图坐标、局部坐标、物体归一化坐标和相关锚点。图片中的底稿编号对应 `strokes[].label`（详细模式为 `commands[].label`）。贝塞尔控制点明确标为 `bezier-control`，不能当成曲线上经过点；旧采样轨迹默认最多取 32 点，完整点可用 `paint_get_strokes({ids:[...]})` 读取。

候选按显式指定、目标底稿、祖先物体底稿、空间相交底稿、其他笔迹排序。例如人体层的眼线即使归属 figure，也能随左眼查询返回。模型需要自己判断这些线是否有用、是否准确；空间相邻不等于语义正确。`guideIds` 可以显式补充候选。全部匹配底稿一次返回，不提供 limit/offset 分页控制。

默认四周留 40 画布像素，可用 `padding` 调整。读取不会改变画布、图层显示、播放位置、复核或历史。底稿观察图显示保留的草稿几何，不应用遮挡或蒙版，因此不代表最终作品。当前画布图遵循播放位置，坐标来自已保存几何；需看完成结果时先完成播放。原始参考使用既有位置变换，与画布裁切对齐；未授权时仅返回 `referenceStatus: access-disabled`，不会泄露参考。

使用习惯：先看图，再读相关线的坐标，自行决定沿用、偏移或修订底稿；小批落笔后复看。此工具不建立自动追随底稿的关系，不把候选线变为强制约束。这是模型接口，不增加人工按钮或面板。默认返回一张四格对照图（参考、当前画布、底稿叠图、整图位置）和精简笔迹坐标；`detail:"full"` 按需读取原始几何、多种坐标及独立图片，`includeImage:false` 只读取坐标。图片各面板的 `imageToDocument` 已包含面板偏移，模型无需自行推断截图布局。


## 批次依据与会话记录

`paint_submit` / `paint_revise` 支持可选 `basis:{guideIds,note}`，省略或没有底稿仍可落笔。实际调用独立记录，返回 `callEvidence`；用 `paint_export_document({section:"evidence",compact:true,limit:100})` 分页读取，按需 includeImages/imageIds，或用 sessionId 读取旧会话。参数与记录边界详见 [模型接口](agent-guide.md)。

## 原子化笔迹平滑

- 新笔迹：在 `paint_submit` 的单条笔迹上设置 `smoothing: 0..1`，落笔时完成画后平滑。省略或 0 保持原线。手动画笔的「落笔平滑」在抬笔时应用。
- 旧笔迹：`paint_smooth_strokes({ids: ["stroke-id"], smoothing: 0.5})` 一次设置 1–50 笔；`note` 可选。界面沿用已有笔迹选择器，调整「所选笔迹平滑」后点「应用平滑」。
- 参数保存在笔迹上，每次从保留的原始几何重算，不叠加磨损。设为 0 恢复原始轨迹；撤销恢复整个操作。
- 支持经过点、控制点、路径及手动采样笔迹。仅作用于画笔，不作用于填色和橡皮；任何一笔无效时整批不修改。
- 在画布坐标中按弧长平滑；固定端点、共享锚点和声明尖角，并保护采样轨迹中的明显锐角。限制普通点偏移，保守强度下主要减轻细小起伏；不会自动修正错误造型。
- 原始压力与显式压力设置独立保留；平滑后仍沿轨迹使用这些压力。图层、遮挡、回放及导出沿用原流程；受影响的复核标为待更新。
- 不新增工作阶段、预览确认或审核轮次。模型先看底稿与参考，理解整条弧线的走势和关键转折，再选点、按需平滑，在原有局部回看中判断效果。必要时重画，不以提高平滑强度替代形体判断。

实现说明：这是对模型／用户已有轨迹的受限画后平滑，不读取参考图像，不提取或自动描摹参考路径。现有 R3 示范画稿不会自动批量应用平滑，也不因工具升级获得新的美术验收结论。
