# 子 agent 阶段复核

本要求由程序随对应阶段说明返回，主绘画 agent 使用宿主提供的子 agent 工具执行。网页本身不启动模型，也不能认证审核者身份；返回要求不等于已经开过子 agent。没有可用的子 agent 能力时明确报告未执行，不得改写为已独立通过。

## 介入位置与两次调用

固定介入点只有 1A 整体定位结束、1C 结构修稿结束、1F 第二轮清线审核。1F 第一轮结构与造型审核仍由主 agent 按原流程执行；子 agent 的初审和复核都属于第二轮内部，不新增第三轮正式审核。1B、1D、1E 不固定开子 agent。

每个介入点先开一个独立子 agent 做初审；主 agent 根据明确问题修订，再新开另一个子 agent 做最终复核。即使初审没有阻断项，也进行第二次独立复核，不强行改笔。每个介入点本次审查最多两次子 agent 调用；最终复核后决定通过或待修，不自动开第三次、不换审核者刷通过。最终仍有阻断项则停留在相应阶段，记录原因及修稿建议；用户要求继续的新一轮另行记录，旧结论不可挪用。

审核者只观察和报告，不修改画布或替主 agent 推进阶段。初审先看参考整图、当前画布整图、当前阶段要求及必要局部，不先看主 agent 的通过结论。最终复核者先独立看修后整图形成判断，再读取初审问题与修改记录，逐项确认解决情况和新增退步；不能仅检查被指出的局部。

## 阶段重点

- 1A：既检查比例、姿态、关节端点、重心和负形，也检查人体构造方法。头、胸廓、骨盆和肢体链应支持同一个姿态；不能以衣袖、鞋或几个体块符号代替结构判断。不要求五官、衣发、精细轮廓。
- 1C：确认主要结构偏差已修正，体积、透视、连接、遮挡及角色主要特征足以支持细化；不按清线完成度扣分。
- 1F 第二轮：边界归属、接头、遮挡起止、重复杂线与线条轻重；使用现有整图、镜像、局部及诊断材料。发现明确结构破坏也须报告，但不重新重复全部第一轮项目。

## 宽容度与通过标准

不设总分及像素误差百分比，不要求逐像素临摹。默认通过阈值是 **零个有充分证据的主要阻断问题**；允许少量不影响本阶段目标的轻微偏差，并在报告中保留。

- `major`：明显改变主要姿态或比例、关节连接不成立、关键前后关系相反，或在 1F 主要边界缺失、误接、穿线使物体归属不清。必须给出整图影响和可定位的参考／画布事实。
- 1F 的主要阻断也包括有充分证据的整体完成度损失：多处简化共同导致主要体积平面化、内部结构不足或标志性特征明显流失。须指出具体区域与共同影响，不能仅凭风格偏好、缺少上色或 minor 数量判定。清线通过需要本阶段质量要求成立的正面证据；不能只依据封闭、采样点分隔或物体可辨认。
- `minor`：轻微曲率、局部距离、线条节奏或细节偏差，没有破坏当前阶段整体关系。列为建议，不仅因它存在就拒绝通过，也不按数量自动升级；多个小偏差共同破坏整体时须说明共同影响。
- `uncertain`：衣物遮挡、风格化或材料不足，不能确定有错。保留范围和不确定原因，不强行改成教材比例。若缺少当前整图或关键部位证据而无法作出判断，结论为 `needs-evidence`，不能冒充通过。

可记录 0–1 的主观 confidence，建议只有 confidence ≥ 0.8 且有明确视觉证据时才把疑似问题列为 major；这个值不是校准过的正确概率，也不由程序按数值自动裁决。低置信度问题优先补看已有参考局部，不仅凭猜测阻断。最后复核建议为 `pass`、`needs-work` 或 `needs-evidence`：无 major 且材料充分可 pass，存在 major 为 needs-work，材料不足为 needs-evidence。

## 图像绑定与日志

每份报告保存阶段、1F轮次（适用时）、初审或最终复核、审核者运行 ID、画布 revision、参考与画布图片 ID／SHA256、逐项参考事实和画布事实、severity、confidence、建议及结论。最终报告额外保存原问题是否解决、是否出现新问题。运行 ID 或哈希本身不证明独立审核已执行，不编造平台签名。

主 agent 保留两份原始报告，在现有 paint_record_review.note 中记录报告位置、审核者和图像版本，并用当前 observationIds 提交实际 paint_record_inspection 对照。不要把 minor／uncertain 建议批量填进 issues；只有确需处理的问题进入持续问题列表。aligned 表示达到本阶段容差，并非毫无差异。已登记的问题仍须按当前图片 resolve 或有证据地 dismiss，不能为了推进伪造 aligned 或清空问题。

1A、1C 用普通 observation 记录协作结果；1F 最终复核通过后才按既有顺序提交 lineart-checkpoint。主 agent 不得把子 agent 的 needs-work／needs-evidence 转录成 pass。相关画面被修改后，旧报告只能作历史证据；仍须对应修改后的版本作判断。

当前实现是程序返回的执行要求，不是自动调度器或独立身份硬门禁。已有图像绑定、持续问题和阶段推进校验继续有效。
