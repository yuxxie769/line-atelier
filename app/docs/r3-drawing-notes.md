# v4 · R3 初音未来半身线稿

本轮以用户提供的 `71badea8d44b41f332c235792eea16c0.jpg` 为视觉参考，在 v4 工作台新建空白工程，从人体占位走完线稿阶段。R3 是这幅绘画的新版本号，工作台仍基于 v4。R2 的全身线稿和独立 HTML 保留。

## 结果与画法

- 画布：1200 × 2000；导出：2400 × 4000 PNG。
- 361 条可编辑笔迹：33 条人体占位、70 条物体草稿、47 条细化稿、211 条正式清线。
- 24 个物体、26 个图层、7 个阶段检查点。正式稿隐藏草稿层。
- 模型观察原图及浏览器实际渲染的局部、全图和水平翻转图，选择经过点、转折、压力和遮挡关系，通过浏览器原生 WebMCP 提交、修改笔迹。
- 本轮没有自动描摹、提取参考像素后复制路径、图像生成器或底图揭幕。曲线拟合、共享锚点和遮挡裁切只处理模型指定的几何。
- 本轮只完成线稿，尚未铺色。逐笔回放是已经保存的绘画命令的执行过程，并不表示播放期间模型在持续思考；修订前后的真实变化保存在阶段检查点中。

## 七个保留阶段

| 阶段 | 实际工作 |
| --- | --- |
| 1A 人体体积与全图占位 | 建立倾斜的头部、眼线、颈柱、肩带、胸廓和上臂体积。 |
| 1B 完整物体草稿 | 覆盖五官、冠发、刘海、双马尾、肩臂、衣领、衬衣、领带、袖套及配饰。 |
| 1C 结构修订 | 根据放大参考修订下颌、中央刘海与衣领；此时的衣领深度仍在后续审核中继续修正。 |
| 1D 细化草稿 | 明确眼睑、虹膜、发夹厚度、耳麦、袖口及衣物连接。 |
| 1E 独立清线 | 重新选择连续经过点与压力，不把全部草线直接描深；按物体保存清线层。 |
| 1F 第一轮 | 对照原图、全图和翻转图，检查头倾、眼睛透视、肩颈、胸廓、上臂和长发动势。 |
| 1F 第二轮 | 放大检查边界、接头、遮挡和线宽，结合缺口扫描及区域连通性修正。 |

正式通过记录对应最终修订 24。中间修改导致失效的旧审核记录保留，最终两项审核均在 1F 中重新核对；没有把旧记录继续当作当前通过凭据。

## 视觉复核中实际修正的问题

1. 左侧低处发束画得过长，且下颌、颈部穿过发梢。缩短并重新组织各层发梢，在真实露出位置接出脸颊和颈线。
2. 左肩与胸前发束有小缺口。将上臂两侧轮廓接入发束边缘；袖口保持包围上臂的独立结构。
3. 右胸上部偏窄，胸牌越出衣料。调整肩臂到衬衣的接点，扩宽对应胸部轮廓。
4. 衣领标记曾误画成立体宝石。放大参考后改成布料上的平面图案，恢复衣领深度并留出边缘间距。
5. 耳麦线与麦头接错，部分线穿过卷发。重新连接麦头边界，并补卷发对麦杆的局部遮挡。
6. 胸前发束的遮挡区与笔迹边界稍有差异。改为共用模型绘制的经过点和曲线参数，避免衣褶从发束边缘露出。

## 程序检查不能只问“有没有漏到背景”

本轮区域检查发现：脸部虽然没有连到背景，却仍通过发梢回折处的小缺口与头发连通。这是实际需要修复的问题。

修正方法是给额头两侧、中央发梢回折、左侧三组发梢设置共享锚点。修改后，脸部种子区域从 545,865 个画布像素缩小到 98,146 个画布像素；中央刘海、右刘海、左刘海、颈部和外侧背景的五个比较点都不再与脸部连通。该数字说明连通区域变化，不是绘画质量评分。

上臂、发夹和衣领也分别进行了内部种子与外部比较点检查。检查依据是真实可见线稿，未使用虚拟封口，没有自动修改画面。

缺口扫描仍会报告一些开放的发丝、睫毛、衣褶和画面裁切端点。本轮没有为了清零警告而把它们强制闭合。后续检查应继续以物体语义和实际渲染为依据。

## 压感与图层

主轮廓、发丝、眼睑、脸部和衣褶采用不同线宽；多数正式笔迹的经过点带有变化的压力。睫毛外侧较重，鼻侧收细，发梢保留尖端；下颌还使用了局部线宽修改。

左马尾按后部和胸前片拆为两个物体，避免前后穿插时形成循环遮挡。衣领、领带、衬衣、皮肤、袖套和配饰分别保留归属，遮挡由局部区域描述。区域本身不会成为画布上的填色命令。

这是一版完成基本线稿流程的模型临摹。表情细节、发丝节奏和衣褶复杂度仍比参考图简化，不宣称达到原视频的商业插画精度。后续上色应在此结构基础上按头发、皮肤、服装和配饰分区，继续采用大色块、阴影、高光和整理的顺序。
