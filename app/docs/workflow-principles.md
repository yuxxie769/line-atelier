# 模型绘画工作流原则与线稿质量标准

适用：Line Atelier v4 模型绘画。本文是作画流程与验收标准的唯一维护正文；用户在当前任务中的明确要求优先。它约束实际作画，不要求维护代码或文档时执行一轮绘画。

维护位置：仓库 `docs/WORKFLOW_PRINCIPLES.md`。网页规范、工具返回正文和复制绘画要求由此生成，不另行维护规则。工具参数见模型接口说明，实施状态与历史作品记录不作为新的作画规则。

## 名词与绘画性质

- **参考图**：供观察和对照的目标图像。
- **绘画性质**：默认按参考图临摹，保留其形体、特征与风格；改编或创作按用户明确要求。
- **底稿**：作品中保留的定位线、体块和草稿，供后续细化与清线。
- **底图**：垫在画布中辅助对照的图像，与底稿笔迹区分；参考图用作底图时也不算已画出的作品。
- **当前画布**：当前进度下实际画出的作品，不含参考图叠加或检查标记。

## 开始绘画任务

开始或继续绘画前读取本规范，并调用 `paint_get_state` 确认作品、画布尺寸、图层、阶段、播放位置与参考图访问状态；按需用 `paint_get_scene` 读取对象和锚点。网页的状态结果默认包含 `drawingProtocol.text` 正文及 `sha256` 版本标识。已读取同一版本后，后续状态查询可用 `includeProtocol:false` 仅保留版本信息；版本变化时重新读取正文。

现有作品沿用其尺寸、坐标和阶段，不默认从空白重画。新作品建立画布后重新准备参考图；读取未开启或参考图缺失时明确说明，不能声称看过参考图。修订范围由用户任务决定，半身或局部参考图不要求补出画外人体。

模型观察参考图并选择几何、线宽、力度、对象与遮挡关系；平台执行插值、平滑、编辑和渲染。从参考图提取的线稿仅供观察，不能自动转换为作品笔迹、区域蒙版或上色路径。

## 每个部位的执行循环

1. **先看图。** 用 `paint_inspect_context` 取得参考图、当前画布、底稿叠图和坐标。实际查看图片，仅读坐标或 Base64 不算看图。
2. **确定依据。** 以参考图确定目标形状，读取底稿 ID 和经过点／锚点，分清它提供的位置、方向、体积或轮廓依据。改形前先找出当前偏差，再决定沿用或修稿；没有明确偏差不随意改形。对象不明或数据不全时补查，不重估全部位置。
3. **小组落笔。** 用 `paint_submit` 或 `paint_revise` 提交一组相关笔画。`basis.guideIds` 引用实际底稿，`basis.note` 用一句话说明为何沿用；需改形时说明哪里偏、依据什么、怎样改。无需逐笔报告；省略 basis 仍可执行，日志记为未提供。
4. **对照复看。** 用 `paint_inspect_context` 或 `paint_snapshot_region` 看本次结果，核对范围、revision 和播放位置；动画未完先 finish。对照参考图检查原先的偏差是否缩小、相邻结构是否受损，不能只看线条是否顺滑。改偏了就修正或回退，不确定则标为待核实。部位完成后退回整体对照。

同一部位可复用有效上下文；形状、底稿、坐标框或遮挡有相关变化时重新观察。底稿缺失或有误时，简述原因后补稿、修稿或自主落笔；空白起稿先按参考图定位。不增加落笔拦截、思考表单或审核轮次。

默认点坐标为整幅画布像素；`space:objectId` 使用对象 frame 对应的局部坐标。截图像素须经 `imageToDocument` 换算。贝塞尔控制柄通常不在曲线上；平滑／裁切后的源经过点与可见轨迹也可能不同，按返回的 `kind`、`smoothing`、`trim` 和 `renderedEndpoints` 区分。共享锚点与几何编辑的具体参数按接口说明读取。

平滑随落笔或单次修线完成，不增加独立阶段。保持有意义的转折与曲线节奏；平滑不能代替形体判断。

## 阶段与记录

完整线稿内部依次为：1A 整体定位 `layout` → 1B 完整粗稿 `rough` → 1C 结构修稿 `structure_review` → 1D 细化草稿 `refine` → 1E 独立清线 `clean` → 1F 两轮整体审核 `lineart_review`。已有作品从当前适用阶段继续；发现问题时回到相应阶段修正。

线稿通过后，按头发大色块 → 皮肤底色 → 服装大色块 → 配饰／鞋履底色 → 阴影覆盖 → 高光整理 → 局部复核推进。对象、图层前后关系和作画时间顺序分别管理；上色使用模型规划的连续宽笔与区域叠层，不用像素差值补丁掩盖线稿问题。

`paint_record_review` 记录实际观察到的问题、动作与结论，相关修改后复查失效项；检查点保存作画里程碑。短说明、工具成功、记录数量或程序测试通过，都不能单独证明模型正确理解了参考图、完成了视觉复核或达到美术质量标准。

## 工作流原则

1. **理解形体优先于复制线条。**
   临摹首先还原姿态、透视、人体比例、体积和遮挡关系。允许调整局部线条，使结构更合理，但应保留参考图的角色特征、动作和风格，不能擅自改成另一种造型。
2. **结构正确后，继续检查美感。**
   人体合理只是基础，还要检查轮廓是否舒展、曲线是否自然、疏密是否协调、局部是否适合整体。避免每个部位单独看都成立，拼起来却僵硬、不协调。
3. **先建立人体，再组织人体周围的物体。**
   先明确头、胸廓、骨盆、四肢、关节和脚的体块，再画衣服、头发与配饰。衣袖包住手臂，鞋包住脚，不能用衣物轮廓代替人体结构。
4. **从大形逐步收敛到精细线稿。**
   依次完成整体占位、体块草稿、结构修订、细化草稿、正式清线。前期允许试探；进入清线时必须选择、修正和重画，不能把全部草稿直接描深。
5. **每个物体都要有可解释的完整边界。**
   可见轮廓应连续，线端应接到明确位置，或在真实遮挡处结束。被遮住的边界可以不画，但模型必须理解它如何延续。衣褶、发丝、结构提示线可以开放；**“闭合”主要要求物体边界成立，不是把每根线都接成圈。**
6. **每个部位完成后，必须退回整体观察。**
   检查它与相邻部位的比例、位置、方向、负形和重心关系。局部修改若影响整体，应连带调整相关结构。
7. **在 1F 统一进行两轮不同目的的审核。**
   审核依据必须是实际渲染后的画面。发现问题就修，再检查受影响的部分；两轮分别检查结构与造型、清线质量；质量未达标就返修，并复查受影响部分。
8. **不理解名称时，仍然可以理解几何。**
   遇到无法识别的配饰或物品，先观察外轮廓、主要平面、厚度、开口、连接和遮挡，尽量还原参考图中的形状结构。暂时不确定的部分保留为待核实项，避免凭空补出复杂结构。

## 1F：两轮审核分别检查什么

| 轮次 | 检查重点 | 必须回答的问题 |
| --- | --- | --- |
| 第一轮：结构与造型审核 | 透视、人体、体块、关节、遮挡，以及比例、轮廓、曲率、负形、整体美感 | 形体与连接成立吗？哪个在前？姿态是否合理？放回全身是否自然协调？关键角色特征是否保留？ |
| 第二轮：清线审核 | 边界、接头、线条轻重、重复线和杂线 | 每个物体是否读得清楚？有没有漏边、穿线、误接或仍未确定的草线？ |

两轮正式审核统一安排在 1F（lineart_review），不再在 1C 单独设置正式审核关卡。1A–1E 仍边画边观察和修正，每个局部完成后退回整体对照，但这些过程检查不另计审核轮次。

每轮都要结合参考图与实际渲染后的当前画布；整体审核还应查看缩小图和水平翻转图。第二轮使用缺口扫描与泄漏预览辅助判断。发现结构问题回到相应作画阶段修正，返回 1F 复查受影响项；不能为了凑轮数重复无关检查。

## 线稿的基本质量要求

| 维度 | 达标标准 |
| --- | --- |
| 人体与姿态 | 头、躯干、骨盆和四肢属于同一姿态；关节连接合理，双脚与承重关系成立 |
| 透视与体积 | 同一物体的方向、截面和厚度一致；袖口、鞋口等开口围绕对应体块 |
| 物体边界 | 不依赖颜色，也能辨认主要物体及其归属；可见外轮廓没有无依据的缺口 |
| 遮挡关系 | 前后关系明确；后方线条在正确位置消失，没有穿过前景物体 |
| 连接关系 | 肩接手臂、腕进入袖口、脚进入鞋内；连接处没有脱节、错位或不自然的收缩 |
| 线条完成度 | 已去除重复试探线、误线、毛刺和无意义碎线；长曲线流畅，尖角保留必要转折 |
| 线条层次 | 主轮廓、内部结构和细节有轻重区别；线宽变化服务于形体与遮挡 |
| 整体美感 | 缩小后轮廓清晰，比例协调，曲线有节奏，局部不会突兀地破坏整体 |
| 临摹一致性 | 保留参考图的姿态、主要比例、标志性轮廓和物体布局；合理修形不改变核心设计 |
