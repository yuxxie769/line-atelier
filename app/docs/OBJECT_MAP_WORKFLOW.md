# 轻量全局物体图规则

1B 第一次落笔前，先读取一次覆盖整幅画布的当前原参考，并把返回的 `observation.id` 交给 `paint_record_object_map`。

一次记录全部主要身体部位、头发组、衣物、配饰、道具及重要开口、接触和遮挡。粒度保持在整只手、整只脚、主发束、袖子或配饰，不拆成指节、发丝或衣褶。同一对象被遮开的片段放在同一项的多个 `visibleMasks` polygon 中。

观察遮罩只负责对象身份、位置、局部裁图和复看。它不是作品选区、裁切路径或绘画路径，也不会自动保证造型准确。1B 及后续新笔迹必须携带有效 `mapItemId`；后续阶段继续使用同一份物体图，发现对象身份或遮罩范围错误时用 `action:"correct"` 修正原记录。

局部绘制仍以原参考为最终依据。读取对象遮罩和局部裁图后，还要比较已有底稿与当前画面，再自行决定坐标、曲率、连接和遮挡。
