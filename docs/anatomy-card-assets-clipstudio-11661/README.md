## 调用规则

1. 每次草稿只从本目录选择一张卡片；不能再调用旧的 `anatomy-card-assets/v1–v3` 混合包。
2. 先执行文章顺序：比例中线 → 动作基线 → 关节点 → 简单形状 → 躯干/四肢 → 细节检查。
3. 卡片图片是“观察顺序与结构提示”，不是描摹目标；目标图的姿态、比例、角色特征优先。
