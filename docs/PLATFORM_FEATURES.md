# Line Atelier 当前平台功能清单

范围：v4 · R3 底稿与平滑整合版，依据当前主入口 `app/index.html`、`app/app.js`、几何模型、渲染器与工具注册表核对。本文记录现有功能，不将实施规划或历史实验脚本算成已上线能力。

## 1. 版本和交付边界

| 项目 | 当前状态 |
|---|---|
| 主要用途 | 模型观察参考后，提交自己选定的笔迹并根据结果修订；页面承担执行和记录 |
| 当前示例 | R3 初音未来半身线稿，1200 × 2000；361 条笔迹，其中 211 条正式清线；七个检查点；尚未上色 |
| 本轮融合 | 用户附件的隐藏底稿与坐标检索能力＋模型优先紧凑返回＋当前平滑能力；不覆盖附件原件 |
| 历史入口 | R2 全身线稿、旧结构修订稿与相应独立 HTML |
| 独立文件 | R3 HTML 内嵌程序、样式、R3 工程和参考，可单独打开；外部链接的旧版另行打开 |
| 网页模型 | 不内置模型、API Key 或模型推理后端 |
| 本轮美术结果 | 没有重画或新验收；工具整合不等于作品达到质量标准 |
| 保存与发布 | 源代码、可下载版和网站保存版本分别维护；保存网站版本不等于更新线上页面 |

## 2. 输入、画布和显示

- 新画布默认 1200 × 1600，可指定宽高、标题和背景；R3 示例尺寸与新建默认值不同。
- 手动画笔、铅笔、橡皮，颜色、粗细、不透明度、压力响应、起收笔及可选抬笔后平滑。
- 鼠标或触笔 Pointer 输入；触笔可带压力，模型直接指定压力值，不需要硬件模拟。
- 画布缩放与适配、参考叠图、局部放大、对应参考对照、同步水平翻转和整图位置框。
- 缩小显示时按显示分辨率重绘静止画面中的源几何，改善细线断续；回放与静止显示使用适合各自场景的渲染方式。
- 曲线练习、示例载入、人体底稿和七阶段查看器。阶段查看与实际恢复检查点是不同操作：查看器用于观察，恢复会修改当前工程并可撤销。

## 3. 参考与模型上下文

| 功能 | 已有行为 | 重要边界 |
|---|---|---|
| 参考导入 | 上传／拖入 PNG、JPEG、WebP，界面提示最大 12 MB；保留原始图片、比例及画布放置变换 | 新建画布会清除当前参考；绘画工程 JSON 不内嵌参考像素 |
| 原图与对应裁切 | 整图缩略图、同文档范围的参考局部、缩放和翻转 | 遵守「允许模型读取参考图」开关 |
| 辅助参考线稿 | 本地亮度边缘／局部对比度提取，仅供观察 | 不是 Anime2Sketch；可能有阴影伪边或漏线；不会自动生成作品指令 |
| 部位解析 | 按唯一名称 query、objectId 或 region 查询 | 模糊或不存在时明确返回候选或错误；不猜物体身份 |
| 底稿发现 | 按显式 guideIds、目标物体、父级物体及空间相交检索；隐藏底稿也可返回 | 空间相关只表示候选，模型自行判断是否有用 |
| 默认上下文 | 一张四格图＋精简笔迹 ID／名称／整图坐标＋相关锚点；每页默认 24 条 | 图片按页标注底稿编号；不是整幅无限量几何一次返回 |
| 完整详情 | `detail:"full"` 返回原始几何、意图、多种坐标、参考局部、画布局部、底稿独立图、叠图、整图定位 | 按需开启，避免无谓增加上下文 |
| 仅坐标 | `includeImage:false` 跳过图像渲染；分页、显式补充 guideIds | 只查坐标不等于视觉观察 |
| 坐标准确性 | 整图坐标、局部坐标、对象归一化坐标、图片到文档变换 | 控制柄不等于经过点；平滑／裁切后额外标明参数及处理后端点 |
| 无作品副作用 | 读取不改图层、笔迹、播放位置、撤销历史或复核 | 底稿图故意展示保存的草稿几何，不应用蒙版／遮挡；当前画布图遵循播放位置 |

默认图片的 `maxSize` 控制单个观察区域的渲染尺度，不是最终四格合图的最长边；合图还包含四个面板、间距与标题。参考权限未开启时返回 `access-disabled`，无参考则为 `missing`。

## 4. 笔迹与曲线

| 能力 | 当前实现 |
|---|---|
| 输入几何 | through 经过点、control 二／三次贝塞尔控制点、path 绝对 M/L/Q/C/Z、手动 points |
| 一次落笔 | 一条 path 只允许一个 M；需要抬笔时拆成不同笔迹 |
| 源几何保存 | 保存稳定 ID、几何、笔迹意图、物体、图层和阶段；compact 导出可省略可重建采样缓存 |
| 默认曲线连接 | through 分段插值；tension 调整弯曲；corners 及锚点 corner 保留尖角 |
| 受限平滑 | 单笔 `smoothing:0..1` 随落笔应用；旧笔迹一次调整 1–50 条；每次从原始几何重算，0 恢复 |
| 平滑保护 | 保留端点、共享锚点和声明尖角，额外保护明显锐角；限制普通轨迹偏移；不能自动纠正人体或错误造型 |
| 局部编辑 | 改源点、控制点或共享锚点；共享锚点可指定 tangent；关联曲线重新计算 |
| 裁切 | trim 按弧长保留区间、保留源几何，适合线端进入遮挡 |
| 局部修订 | 原子替换、删除、指定位置插入；保留稳定 ID 与顺序；无效批次不改工程 |
| 可选试画 | 对现有笔迹做候选替换并返回区域 PNG，不改变当前工程；没有强制预览确认流程 |

渲染中心线仍是细分轨迹，画笔通过许多短段圆头笔触生成。没有实现完整的连续变宽外轮廓笔刷；增加平滑不会自动解决所有边缘和线条美感问题。采样旧笔迹无法恢复已经丢失的原始控制点。

## 5. 压力与线宽

- 经过点可带 pressure；`taper:[start,middle,end]` 控制起笔、中段和收笔。
- `pressureProfile` 用沿线多节点描述多次提按，覆盖源点压力；`pressureCurve` 将输入压力映射为线宽响应。
- `pressureFloor` 控制最低相对笔宽；界面有响应预设与试笔预览。
- 已有笔迹可修改压力曲线、沿线压力、最低线宽或基础宽度，保持源中心线几何。
- 局部线宽编辑使用 range、factor、feather，保留范围外轻重；累计倍率受最大笔宽限制。
- 压力编辑可撤销并参与导出与回放。平滑与压力各自保留，不把修形和改轻重绑定成固定流程。

## 6. 物体、图层、蒙版与遮挡

- 对象包含名称、frame、parent、material、阶段和简短备注；frame 为整图坐标，parent 不叠加空间变换。
- 共享锚点提供相接依据；局部空间适合按物体组织几何。
- 图层从下到上合成，支持显示、锁定、不透明度、名称、分组和角色；图层时间与绘画阶段独立。
- 混合模式有正常、multiply、screen；clipTo 将上层裁切到下方图层。
- 支持模型绘制的多边形 masks，以及对象 scene.regions 和前后 occlusions。
- 纯线稿也可去除后景被遮部分；透明对象不能充当不透明遮挡；循环遮挡须拆分物体。
- 隐藏某个前景线条图层，不会自动撤销其物体遮挡关系。底稿观察图则可显示原始草稿，便于理解被遮结构。
- hideAtStage / hideAtCommand 可随绘画进度隐藏草稿；手动显示相关层会取消相应自动隐藏设置。
- 图层缓存支持快速重新合成和局部编辑后的相关层重绘。

不可见区域是模型主动定义的几何辅助，不能代替真正的可见边界。区域泄漏检查以实际可见线稿为准，不让虚拟边界替漏线封口。

## 7. 检查、审核和阶段管理

| 功能 | 做什么 | 不做什么 |
|---|---|---|
| 接头检查 | 检查可见清线声明的相接／遮挡端点，返回相关 ID、坐标和距离 | 不覆盖所有未声明漏口 |
| 主动缺口扫描 | 扫描悬空端点、邻近缺口、短线；考虑距离、方向、线宽及实际可见性 | 不强行闭合发丝和衣褶，不自动通过审核 |
| 区域泄漏预览 | 给区域种子和可选比较点，在可见线稿上计算连通性 | 不自动补线，不靠隐形边界封闭 |
| 检查标注 | 临时画布覆盖层及带标注局部；可清除 | 不进入作品 PNG；改图／改层／改播放后报告失效 |
| 复核记录 | 保存范围、相关对象／笔迹、状态、简短观察和声明的 evidence | evidence 字段是模型陈述，不是自动收集的完整读图证据 |
| 修改失效 | 相关几何、对象与遮挡变化令复核 stale；更新的 needs-work 可撤回旧 pass | 不把旧通过永久沿用 |
| 1F 两轮 | 第一轮结构与造型，第二轮清线质量；需顺序且在 1F 记录 | 不增加第三轮固定审核 |
| 上色门槛 | workflow.enabled 时，当前两轮未有效通过会拒绝颜色阶段提交 | 没有先查底稿才允许落笔的新门槛 |

已定义八个主阶段：线稿、头发、皮肤、服装、配饰／鞋履、阴影、高光整理、局部复核。线稿内部是 1A–1F 六个阶段。其他颜色阶段顺序主要属于模型执行规范，并非每一步都有程序硬性拦截。

## 8. 回放、历史、保存与导出

- 回放支持播放、暂停、完成、seek、单笔步进和 0.1–80× 速度；1× 约为每秒 360 文档像素，抬笔停顿 100ms。
- 隐藏图层不会占用无画面变化的动画等待，笔迹仍保存在工程内。回放不生成新笔迹。
- 支持撤销／重做，最多保留 30 个历史条目；当前 WebMCP 有 undo，redo 保留在界面／引擎层，没有单独注册同名模型工具。
- 最多八个检查点；可列举、保存、恢复，恢复可撤销。检查点不嵌套复制其他检查点。
- IndexedDB 本机自动保存工程、简要要求和参考原图数据；不是跨设备同步。保存失败会提示导出工程。
- JSON 工程可导入／导出，包含源几何、场景、图层、阶段、复核与检查点；参考图片单独管理。
- PNG 从当前绘画几何按目标分辨率重绘，界面有 1×／2×／3×，默认 2×，最长边不得超过 4096；遵循当前图层和播放状态，不含参考或检查标注。
- 模型工程导出支持 manifest、commands 分页、checkpointId、compact；分页期间 revision 应保持一致。模型接口不单独提供一个完整 PNG 文件下载工具，图像读取走 snapshot 系列。
- 独立 HTML 构建包含代码、样式、示例工程、参考及部分说明。它保存的是构建时示例；普通用户当前编辑后的作品应导出 JSON，不会自动改写下载的 HTML 源文件。
- 页面活动列表最近 30 条，工程变更事件最多 300 条，复核最多 100 条；目前没有完整、持久的按笔画组读图证据链。

## 10. 主要容量与限制

| 项目 | 当前限制 |
|---|---|
| 文档每边 | 64–2048 整数像素 |
| 命令总数／单批 | 60000／10000 |
| 单笔最终采样点／全图点 | 4096／600000 |
| through 源点 | 2–256 |
| 图层／阶段 | 64／24 |
| 对象／锚点／区域 | 128／2048／256 |
| 多边形蒙版 | 512 个，总顶点 300000 |
| 笔宽 | 0.25–180 文档像素 |
| 上下文分页 | 默认 24，最多 200 条；显式 guideIds 最多 200 |
| 上下文 maxSize | 256–1024，默认 640；四格图总尺寸另计 |
| 普通局部图 | scale 0.25–4，单边输出最多 4096 |
| 检查标注图 | 单边最多 2048 |
| 平滑／压力编辑批次 | 1–50 条 |
| 工程导出笔迹分页 | 默认 100，最多 200 条 |

这些是容量与参数校验，不能保证在极限规模下仍有流畅性能。没有承诺实时多人协作、模型自动调度、完整操作审计、跨设备作品同步、SVG 原生导出、专业纹理笔刷或自动参考描摹。

## 11. 尚未实施的两项规范

固定加载绘画正式指令，以及每组一句 basis 关联读图—坐标—落笔—结果图，均见 `DRAWING_IMPLEMENTATION_PLAN.md`。当前没有 basis 批次字段、持久会话证据日志或相关查询工具。不得把规划示例当作现有接口调用。

本次测试验证程序能力和状态一致性，不证明模型在实际绘画中每次都会主动遵循，也不证明当前示例线稿已达到精修标准。
