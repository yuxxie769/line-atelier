# 模型绘画工作流原则与线稿质量标准

适用：Line Atelier v4 模型绘画。本文件维护核心原则；阶段要求维护在 docs/workflow-stages/，共同构成正式规范；用户在当前任务中的明确要求优先。它约束实际作画，不要求维护代码或文档时执行一轮绘画。

维护位置：仓库 `docs/WORKFLOW_PRINCIPLES.md`。网页规范、工具返回正文和复制绘画要求由此生成，不另行维护规则。工具参数见模型接口说明，阶段正文同样由源文件生成；实施状态与历史作品记录不作为新的作画规则。

## 名词与绘画性质

- **参考图**：供观察和对照的目标图像。
- **绘画性质**：默认按参考图临摹，保留其形体、特征与风格；改编或创作按用户明确要求。
- **底稿**：作品中保留的定位线、体块和草稿，供后续细化与清线。
- **底图**：垫在画布中辅助对照的图像，与底稿笔迹区分；参考图用作底图时也不算已画出的作品。
- **当前画布**：当前进度下实际画出的作品，不含参考图叠加或检查标记。

## 开始绘画任务

开始或继续绘画前读取本规范，并调用 `paint_get_state` 确认作品、画布尺寸、图层、阶段、播放位置与参考图访问状态；按需用 `paint_get_scene` 读取对象和锚点。网页的状态结果默认包含 `drawingProtocol.text` 正文及 `sha256` 版本标识。开始或恢复任务使用默认完整返回；已读取同一核心版本后的连续操作才可用 `includeProtocol:false` 省略核心正文，当前阶段正文仍返回。版本变化时重新读取。

现有作品沿用其尺寸、坐标和阶段，不默认从空白重画。新作品建立画布后重新准备参考图；读取未开启或参考图缺失时明确说明，不能声称看过参考图。修订范围由用户任务决定，半身或局部参考图不要求补出画外人体。

模型观察参考图并选择几何、线宽、力度、对象与遮挡关系；平台执行插值、平滑、编辑和渲染。从参考图提取的线稿仅供观察，不能自动转换为作品笔迹、区域蒙版或上色路径。

## 工作流原则

1. **理解形体优先于复制线条。**
   临摹首先还原姿态、透视、人体比例、体积和遮挡关系。允许调整局部线条，使结构更合理，但应保留参考图的角色特征、动作和风格，不能擅自改成另一种造型。
2. **结构正确后，继续检查美感。**
   人体合理只是基础，还要检查轮廓是否舒展、曲线是否自然、疏密是否协调、局部是否适合整体。避免每个部位单独看都成立，拼起来却僵硬、不协调。
3. **先建立人体，再组织人体周围的物体。**
   先明确头、胸廓、骨盆、四肢、关节和脚的体块，再画衣服、头发与配饰。衣袖包住手臂，鞋包住脚，不能用衣物轮廓代替人体结构。
4. **从大形逐步收敛到精细线稿。**
   依次完成整体占位、体块草稿、结构修订、细化草稿、正式清线。前期允许试探；进入清线时必须选择、修正和重画，不能把全部草稿直接描深。
5. **每个物体都要有可解释的完整边界。**
   可见轮廓应连续，线端应接到明确位置，或在真实遮挡处结束。被遮住的边界可以不画，但模型必须理解它如何延续。衣褶、发丝、结构提示线可以开放；**“闭合”主要要求物体边界成立，不是把每根线都接成圈。**
6. **逐批检查实际改动，阶段节点退回整体。**
   每批只检查本次实际改变的部位；空间相邻但没有改动的部位不重复填表。单个改动目标使用局部图；同一批有多个改动目标时只返回一张当前整图，在整体关系中重点观察这些目标，并用同一图片依据分别记录各目标。阶段推进前统一检查整图及当前阶段涉及的部位。若局部修改明显影响全身比例、姿态、负形或重心，可提前补看整图并连带调整相关结构。
7. **不理解名称时，仍然可以理解几何。**
   遇到无法识别的配饰或物品，先观察外轮廓、主要平面、厚度、开口、连接和遮挡，尽量还原参考图中的形状结构。暂时不确定的部分保留为待核实项，避免凭空补出复杂结构。
8. **后续绘画应承接已有底稿。**
   细化、清线和局部修图时，先理解底稿提供的位置、方向、比例、体积与遮挡依据，再决定沿用或修正。底稿服务于参考图，不能机械描摹错误底稿，也不能忽略有效底稿重新估形。清稿的每个小批次必须绑定同部位已确认底稿；画后同时查看参考、底稿和当前清稿，只判断保留、改善或退步，退步时只修当前部位。五项造型检查留在阶段出口。相关工具操作在[操作说明](workflow-actions/local-revision.md)，读取部位上下文时由程序返回，不在首次加载展开。
9. **少量落笔，逐组复看。**
   普通批次提交 1–3 笔，围绕一个具体轮廓或连接关系。所有绘画阶段中，同属一个部位、两端开放且不涉及敏感结构关系的低风险线，可用 `low-risk-clean` 批次提交 5–6 笔；五官、手脚、关节、接头、遮挡和关键转折仍保持 1–3 笔。完成播放后立即对照本批实际改动目标并记录检查，才能继续落笔；整图与未改部位在阶段节点统一检查。
10. **按形体组织每一笔，发现偏差先返修。**
   落笔前找出参考中的起止、凸起、收缩、转向、连接和遮挡位置；笔迹长度服从形状，不用均匀长弧或任意折线吞掉曲率变化。检查为 `different` 或 `uncertain` 时，先修改相关笔迹并重新对照、处理问题，再向其他部位新增。
11. **复杂轮廓使用有目的的复合笔组。**
   一条意图轮廓不等于一条程序路径。进入 1D refine、1E clean 或 1F lineart_review 后，轮廓只要跨越曲率极值、转面、遮挡起止或线条职责变化，就必须按[三号复合笔组 v1](drawing-methods/COMPOUND_V1.md)规划：模型提交一条完整源轮廓、1–2 个有结构原因的抬笔点和全局压力计划，程序自动生成 2–3 条带短搭接的实际笔迹，不额外磨平转折。不得直接手写最终 `compoundId` 绕过规划。
   普通单线只保留给确实能一气呵成的简单扫线，并须声明 `contourMode:"simple-sweep"` 和具体 `simpleSweepReason`；检测为长而复杂的路径即使这样声明也会被程序拒绝。生成笔迹共用 `compoundId`，分别记录 `strokeRole` 与 `joinStyle`。分笔服务于形体和手势，不以短线数量为质量指标，也不把流畅的简单长扫线机械切碎。复合规划仍须遵守底稿绑定、每批实际笔数和图像检查。


## 阶段加载与记录

首次加载阅读本文件，不预先加载全部阶段正文。进入阶段调用 `paint_set_phase`，读取返回的核心原则和当前阶段要求；开始或恢复任务调用 `paint_get_state`，读取当前阶段要求。二者都需要完成强制的绘画指导说明加载。恢复检查点后也读取对应要求。程序负责选择当前阶段，模型负责实际观察与执行，加载成功不等于质量通过。

- [1A 整体定位](workflow-stages/layout.md)
- [1B 完整粗稿](workflow-stages/rough.md)
- [1C 结构修稿](workflow-stages/structure_review.md)
- [1D 细化草稿](workflow-stages/refine.md)
- [1E 独立清线](workflow-stages/clean.md)
- [1F 两轮整体审核](workflow-stages/lineart_review.md)

阶段依次为 1A → 1B → 1C → 1D → 1E → 1F；发现问题返回相应阶段修正。两轮正式审核仅在 1F，不增加逐笔审批或正式审核轮次。固定子 agent 介入点为 1A 结束、1C 结束及 1F 第二轮；每处初审一次，修订后新开子 agent 最终复核一次，再决定通过或待修。程序随这些阶段返回 `stage.agentReview` 的完整要求，按其中容差执行，不无限加审。进入下一阶段前，必须按 `localFeedback.inspection` 取得对照图并调用 `paint_record_inspection` 记录参考形状、当前形状与逐项结论；取图本身不能完成检查。问题自动登记，修正后重新检查。允许退回修稿，不强制发现问题或凑修改次数。


`paint_record_review` 记录实际观察到的问题、动作与结论，相关修改后复查失效项；
