# 全局物体图实施计划

状态：实施方案，尚未修改正式规范或程序行为。方法依据见 [OBJECT_UNDERSTANDING_METHOD.md](OBJECT_UNDERSTANDING_METHOD.md)。

## 1. 实施目标

在 1B 开始时，由当前作画模型一次识别参考图中的主要身体部位、头发、衣物、配饰和复杂关系，为每项对象建立简短解释与固定观察遮罩。后续粗稿、结构修稿、细化、清线和审核复用同一份全局物体图，不生成阶段性的更细遮罩。

实施需要同时满足：

1. 人物作品固定关注手、脚、关节、颈肩及人体进入衣物的位置；
2. 全局物体图覆盖所有主要可见对象，复杂对象保存必要构造与关系；
3. 遮罩表示对象在原参考图中的可见形状和位置，允许同一对象包含多个不连续区域；
4. 遮罩只用于观察和定位，不成为作品几何；
5. 完整识别只集中进行一次，局部绘画只接收当前对象的短信息；
6. 不增加逐对象的其他模型确认或新的正式审核轮次。

## 2. 现状与缺口

当前系统已有以下基础：

- `scene.objects`、笔迹 `part/objectId`、区域和遮挡关系能够表达作品对象；
- `paint_inspect_context` 能返回参考、当前画布、底稿和整图坐标；
- 1D 的 `paint_record_refinement_diagnosis` 能约束当前图像上的一个小批次；
- 阶段检查能保存图像凭据和修改结果。

现有能力仍缺少：

- 1B 开始时对整张参考图的一次对象识别；
- 人物常见部位的固定覆盖要求；
- 与作品蒙版分离的参考图观察遮罩；
- 同一对象多块可见区域的持久身份；
- 从观察遮罩自动定位和裁取局部的机制；
- 跨阶段复用的简短物体解释；
- 将长期对象认识与 1D 一次性修改授权分开的数据结构。

此前设想的“1B 逐对象建立暂定解释、1C 再逐对象确认”不再采用。1B 负责一次建立全局物体图；1C 只检查粗稿是否落实其中的判断。

## 3. 工程数据

### 3.1 全局结构

工程文档新增 `objectMap`。建议结构如下：

```json
{
  "id": "uuid",
  "referenceKey": "reference-and-transform-key",
  "coordinateSpace": "document",
  "status": "ready",
  "observationIds": ["full-reference-observation"],
  "items": []
}
```

`referenceKey` 同时绑定参考图内容和它到画布的坐标变换。改变参考图、缩放、旋转或位置后，旧遮罩不能继续假定有效。

### 3.2 对象记录

每个主要对象保存一项记录：

```json
{
  "id": "neck-band",
  "name": "颈带",
  "category": "accessory",
  "sceneObjectId": "neck-band",
  "relatedObjectIds": ["neck", "front-hair"],
  "form": "一条有稳定带宽、绕颈转向的窄带",
  "relations": "左右露出段属于同一物体；中段被前发遮挡",
  "uncertainty": "背侧扣合方式不可见",
  "visibleMasks": [
    {"id": "neck-band-left", "polygon": [[0, 0], [0, 0], [0, 0]]},
    {"id": "neck-band-right", "polygon": [[0, 0], [0, 0], [0, 0]]}
  ],
  "landmarks": [
    {"role": "occlusion-entry", "point": [0, 0], "occluder": "front-hair"}
  ],
  "status": "ready"
}
```

示例中的坐标只表示字段形状，实际数据使用画布坐标。

字段约束：

- `form`：整体与主要部分，保持一句短说明；
- `relations`：连接、接触、连续性与遮挡；
- `uncertainty`：参考无法支持的判断，可以为空；
- `visibleMasks`：一项对象可以包含多个可见区域；
- `landmarks`：仅保存确有必要的连接、接触、开口或遮挡端点；
- `sceneObjectId`：关联画布中的对应对象；`relatedObjectIds` 只记录需要共同观察的邻接对象；
- `status`：`ready`、`needs-evidence`、`corrected` 或 `stale`。

人体、衣物、头发和配饰使用同一对象格式。身体部位可以在 `category` 中区分，但不建立另一套人体数据系统。

### 3.3 观察遮罩的边界

观察遮罩与现有作品 `masks`、`scene.regions` 和 `occlusions` 分开保存：

- 观察遮罩只描述参考图中的可见归属；
- 作品蒙版影响绘制和合成；
- 场景区域与遮挡决定画布上对象的实际遮挡。

三者不能自动互相转换。观察遮罩使用紧凑的矢量多边形保存，程序渲染半透明颜色；不保存由图像生成工具重绘的分区图。

## 4. 工具设计

### 4.1 1B 全局记录工具

新增 `paint_record_object_map`，在 1B 开始时一次提交完整对象清单：

```json
{
  "observationIds": ["current-full-reference"],
  "items": [
    {
      "id": "raised-hand",
      "name": "抬起的手",
      "category": "body",
      "form": "手腕连接掌部，掌部展开为弯曲指组",
      "relations": "从袖口伸出，与编发和下巴相邻",
      "uncertainty": "部分指根被遮挡",
      "visibleMasks": []
    }
  ]
}
```

工具要求当前整图参考观察凭据，并验证对象 ID、字段长度、多边形有效性、坐标范围和多区域归属。一次调用可以记录整张图的全部主要对象，不要求为每件物体分别走一次工具流程。

记录后返回程序确定性绘制的原图叠加预览。当前模型在同一次 1B 全局检查过程中查看预览；若发现错分，使用同一工具的 `action:"correct"` 修订原对象记录。这个纠错过程不引入其他模型确认。

### 4.2 全局物体图读取工具

新增或扩展只读能力：

- `paint_get_object_map`：返回整图对象清单，可选择是否显示确定性遮罩叠加；
- `paint_inspect_context`：接受 `mapItemId`，自动返回当前对象所需的局部材料。

局部返回包含：

1. 原参考图局部；
2. 同一局部上的固定观察遮罩；
3. 当前画布局部；
4. 关联底稿；
5. 当前对象的一张短说明卡。

裁图范围从 `visibleMasks` 的外接范围自动计算，并根据画布尺度增加留白。若对象有多个距离很远的可见区域，工具可以返回包含全部区域的总览，并按需返回单个可见区域的局部；它们始终共享同一对象记录。

### 4.3 纠错工具行为

后续发现错分时，只能修订同一份 `objectMap`：

- 修改对象名称、解释或未知项；
- 增删可见多边形；
- 合并错误拆开的对象；
- 拆分错误合并的对象；
- 补入初次遗漏的主要对象。

修订保存版本历史。它是对 1B 全局识别结果的纠错，不建立 1C、1D 或 1E 专用遮罩。

## 5. 阶段接入

### 5.1 1A：整体定位

保持现有姿态、人体大体块和负形流程。1A 可以建立作品场景对象，但不要求完成参考图观察遮罩。

### 5.2 1B：全局识别后完成粗稿

进入 1B 后，先取得整张原参考图并调用 `paint_record_object_map`。全局物体图至少覆盖：

- 画面中的主要身体部位；
- 人物固定关注项中实际可见的手、脚、关节、颈肩和衣物交界；
- 主要头发分组、衣物部件、配饰和道具；
- 复杂开口、接触、穿入、挂接、遮挡与分散可见对象。

当前参考缺少有效全局物体图时，1B 的正式粗稿提交被拒绝。允许先记录 `needs-evidence` 对象；它们保留不确定边界，不能被画成未经依据的确定细节。

完成全局物体图后，模型按照它绘制完整粗稿。普通清楚对象不需要额外长解释；复杂对象的记录随局部上下文自动返回。

### 5.3 1C：检查粗稿落实情况

1C 不逐项重新确认物体是什么。它对照参考、固定观察遮罩、全局物体图和当前粗稿，检查：

- 每个主要对象是否画在正确位置并保持正确归属；
- 同一对象的多个可见区域是否由一致构造解释；
- 人体部位、衣物、头发和配饰是否发生混淆；
- 连接、接触、开口和遮挡是否在粗稿中成立；
- 不确定部分是否被克制地保留。

如果粗稿偏离全局物体图，修粗稿。如果检查证明物体图本身错了，纠正对应记录，再继续修稿。物体图不增加逐项子 agent 确认；现有阶段复核只检查实际画面结果。

### 5.4 1D：复用对象记录并展开细节

1D 继续使用 1B 建立的同一份对象遮罩，不生成手指、指节、细发丝、鞋带或衣褶遮罩。

局部诊断改为引用 `mapItemId`，只记录当前画面问题和一个批次关系：

```json
{
  "scope": "local",
  "mapItemId": "neck-band",
  "relationTarget": "统一头发遮挡两侧的带宽和走向",
  "drawingFacts": "右侧露出段过窄并产生无依据折角",
  "decision": "repair",
  "guideIds": ["draft-neck-band"]
}
```

长期的 `form`、`relations` 和 `uncertainty` 已在全局物体图中，不再每批重复。画手时，模型从原图局部理解掌指内部结构并落笔；它不需要为每根手指另建遮罩。

### 5.5 1E：继承清线

清线批次在现有底稿依据之外引用 `mapItemId`。局部上下文返回同一对象解释和遮罩，帮助确认正式线条属于哪个对象。需要重新决定物体身份、主要组成或遮挡关系时返回 1C／1D 处理。

### 5.6 1F：沿用现有审核

不增加第三轮审核。第一轮结构与造型审核读取全局物体图，检查最终线稿是否仍体现对象归属、连续性、连接与遮挡；第二轮继续检查边界、接头和线条质量。

## 6. 注意力控制

实施时执行以下信息预算：

- 完整对象识别只在 1B 开始时集中加载和记录；
- 核心规范只保留一条“先统一解释对象，再画可见片段”的原则；
- 人体固定项使用一张短表，不重复加载人体教程；
- 同一对象的解释和遮罩跨阶段复用；
- 局部工具只返回当前对象，不返回全局清单；
- 每个小批次只出现一个 `relationTarget`；
- 五项结果验收仍放在阶段出口；
- 同一版本的完整操作说明已读取后，连续调用只返回来源、哈希和当前短任务卡。

遮罩颜色和标签只用于临时叠加显示，不作为每次模型输入中的大型图例。模型可以关闭颜色层直接看原图，也可以按当前对象单独高亮。

## 7. 失效与版本规则

- `objectMap` 绑定参考内容与参考到画布的变换；其中任一变化使整份记录进入 `stale`；
- 普通画布笔迹变化不影响观察遮罩，因为它描述原参考图；
- 修改某个对象记录只使该项及依赖它的当前局部授权待复查，不使无关对象失效；
- 合并或拆分对象时更新相关 `mapItemId` 引用并保存历史；
- 旧工程没有 `objectMap` 时正常导入，但不会自动生成虚假的已识别状态；
- 恢复旧阶段工程后，在继续 1B 及后续相关绘画前补做一次当前参考的全局物体图。

## 9. 实施顺序

### 第一步：正式规范减法

把方法中的核心原则和阶段职责并入正式源文档，同时合并现有重复段落。记录修改前后的正文长度，运行协议同步与一致性检查。

### 第二步：全局物体图数据与遮罩渲染

实现 `objectMap`、对象记录、多区域多边形、版本历史和旧工程兼容。实现直接叠加原参考图的确定性遮罩渲染，确认它不会改变原图像素或进入作品合成。

### 第三步：1B 一次全局识别

实现 `paint_record_object_map`、整图预览和纠错行为。加入人物固定关注项与 1B 入口门槛，确保模型在正式粗稿前一次提交完整对象清单。

### 第四步：局部读取与 1C／1D 接入

让局部上下文按 `mapItemId` 从固定遮罩生成观察区域。1C 使用它校正粗稿；1D 复用它并将现有长诊断压缩成当前画面问题和一个批次关系，不生成新的遮罩。

### 第五步：1E／1F 承接

清线依据加入 `mapItemId`；现有两轮审核能够按全局物体图定位对象并检查最终关系，不增加审核轮次。

### 第六步：实际作品验证

使用当前白发少女参考和工程验证：

- 抬起的手；
- 下垂手、袖口与脚后跟交界；
- 颈部环状带饰；
- 编发与后侧长发；
- 脚、鞋口和鞋。

验证从 1B 全局物体图开始，随后完成粗稿、1C 修稿和 1D 局部细化。早先由图像生成工具制作的彩色分区图只作为粒度讨论材料，不进入正式验证或工程数据。

## 10. 验证条件

### 10.1 自动测试

- 旧工程没有 `objectMap` 时可以导入，且状态明确为未建立；
- 全局记录必须绑定当前整图参考观察与当前参考变换；
- 多个不连续多边形可以属于同一对象；
- 无效、自交越界或点数不足的多边形被拒绝或明确规范化；
- 程序能从遮罩正确计算上下文范围；
- 观察遮罩不会成为作品蒙版、笔迹或填色数据；
- 普通绘画不会使全局物体图失效；
- 参考或参考变换变化会使它失效；
- 单项纠错保留历史，并只影响相关局部授权；
- 1D 不能创建阶段专用的细化遮罩；
- `mapItemId`、笔迹对象和局部目标不匹配时拒绝修改；
- 连续局部调用的短返回仍包含对象 ID、来源和版本。

### 10.2 视觉验证

由观察者只看原参考图、确定性遮罩叠加和阶段画稿，检查：

1. 每个主要可见区域是否归属于正确对象；
2. 遮罩是否贴合实际可见轮廓，没有跨入相邻对象；
3. 同一对象被遮挡后的多个区域是否保持同一身份；
4. 手脚、关节、颈肩和衣物交界是否都被覆盖；
5. 1C 粗稿是否落实对象位置、连接和遮挡；
6. 1D 与 1E 是否始终复用原遮罩，没有建立新的细分遮罩；
7. 最终线稿是否能独立读出对象关系，不依赖文字说明。

### 10.3 注意力验证

记录一次完整作品中：

- 1B 全局识别输入与输出长度；
- 同一对象被局部读取的次数；
- 每次局部返回的正文长度；
- 被重复发送的长期说明数量；
- 因误认对象而返工的次数。

新方案应减少 1D 重复字段和长期说明的重复传输，同时不能通过减少必要观察来换取更短上下文。

## 11. 兼容与边界

- 不自动从参考像素生成作品结构，也不自动把颜色或边缘检测结果当成对象；
- 遮罩由模型观察后明确提交，程序只校验、保存和渲染；
- 不要求绘制参考中不可见的完整边界；
- 不按对象数量、遮罩顶点数量或文本长度判断艺术质量；
- 不为手指、发丝、衣褶等建立后续细化遮罩；
- 不增加逐对象的子 agent 审批，也不增加正式审核轮次；
- 实际作品验证通过后，才把稳定规则合并进正式规范；本计划本身不作为绘画时反复加载的提示词。
