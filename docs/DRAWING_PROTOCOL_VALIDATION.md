# 绘画规范入口与加载验证

验证日期：2026-09-07。本记录针对规范统一与入口加载，不是 R3 试画或美术验收。

正式维护正文是 [WORKFLOW_PRINCIPLES.md](WORKFLOW_PRINCIPLES.md)。核心原则、1F 两轮审核和九项质量要求以该文件当前版本为准；加载链路覆盖任务启动、底稿坐标判断、少量落笔、逐批图像复看、先返修再继续、无底稿处理与记录边界。

## 接入与维护

- 仓库根 [AGENTS.md](../AGENTS.md) 要求实际绘画前读取正文，代码维护不触发作画。当前外层迁移目录另有入口指向本仓库；换机器时直接打开本仓库。
- 网页 `paint_get_state` 和页面 API `window.paint.state()` 共用 `api.state`，默认返回 `drawingProtocol:{source,sha256,text}`。已读同版本后可用 `includeProtocol:false` 省略正文；无页面级已读标记，新调用者默认仍能取得全文。
- 网页规范、状态工具与复制绘画要求共用生成内容。修改主文件后运行 `npm run sync:protocol`；`npm run dev`、`npm test` 和构建会同步。`npm run check:protocol` 只读检查一致性。
- `npm run build` 同时重建 R3 单文件版，保证本轮构建的应用和下载版采用相同规范。

项目指令的发现路径与新会话验证方式参考 [OpenAI 官方 AGENTS.md 文档](https://learn.chatgpt.com/docs/agent-configuration/agents-md)。该机制不代表网页调用者会读取本地文件，因此网页入口直接返回正文。
