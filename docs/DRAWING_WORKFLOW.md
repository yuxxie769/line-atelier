# Line Atelier · v4 模型绘画规范与改进计划

更新日期：2026-09-05。适用项目：Line Atelier；开发基线为 v4。v5 仅提供绘画流程和区域叠层的参考思想。

本文记录用户确认的目标、研究依据、绘画执行规范和待开发能力，是后续绘画与改进的工作依据。标为“待开发”的内容尚未成为网页功能。教程描述可借鉴的画法，本项目的阶段安排是为当前任务制定的规范，不代表所有画师都采用同一流程。

## 1. 已确认的目标与边界

1. 模型根据参考图理解物体、位置、体积和遮挡关系，通过 WebMCP 提交自己选择的连续笔迹，并查看结果后修改。
2. 可以用技术手段提取参考线稿，帮助观察。提取结果仅供参考，不直接贴入画布，也不自动转换成画布笔迹、区域蒙版或上色路径。
3. 绘画从整体到局部、从大形到细节。草稿阶段允许线条试探、重叠和暂未闭合；不必故意制造抖动来模拟手绘。
4. 每完成一个有意义的小部分，立即审视该部分及其相邻结构，修正形状、位置和遮挡问题。
5. 第一轮画满全身的线条仍称为“完整草稿”，不等于精细线稿。完整草稿须先通过整体形态复核，再进行独立的清线加工。
6. 清线完成后再次审视整体比例、二次元造型逻辑与参考一致性；有大形错误就回到结构修正，不靠上色掩盖。
7. 线稿阶段合格后，按照“大色块 → 阴影覆盖 → 高光与整理 → 局部复核”推进颜色，减少碎点与像素式补丁。
8. 物体、图层和绘画时间顺序分别管理。物体概念从起稿时建立，不能到上色时才划分。
9. 视觉目标仍是最初截图中的完整、准确、精细的线稿。逐笔播放、笔迹数量或程序检查通过，都不能替代美术质量验收。

## 2. 人类绘画经验及其应用

| 研究依据 | 可借鉴的经验 | 本项目采用的规则 |
| --- | --- | --- |
| [Proko：Project — Measure Proportions](https://www.proko.com/course-lesson/project-measure-proportions) | 先比较最大的形状，再向较小细节推进 | 起稿先建立全身比例与主要体块；各物体内部也按大形到细节处理 |
| [Proko：How to Draw Accurate Proportions](https://www.proko.com/course-lesson/how-to-draw-accurate-proportions) | 以测量和持续自我反馈修正比例，并反复退回整体观察 | 局部画完即复核，同时安排全身检查，防止只盯住当前细节 |
| [Art Rocket：Character Portrait Illustration Workflow](https://www.clipstudio.net/how-to-draw/archives/170075) | 草稿可以保留待完善之处，之后降低草稿透明度进行清线，并借助翻转检查比例 | 草稿与清线分别保存；清线包含重新判断形状，不能只是机械覆盖旧线 |
| [Eridey：Tips for Drawing Digital Anime Line Art](https://www.clipstudio.net/how-to-draw/archives/165695) | 线宽、方向和边缘表达体积、材质与视觉重点；绘制时可调整局部形状并翻转检查 | 清线同时处理形体、线条轻重、接头和取舍，而非仅统一平滑或细化线宽 |
| [Proko：How to Draw the Calf](https://www.proko.com/course-lesson/how-to-draw-the-calf-anatomy-for-artists) | 小腿轮廓由肌肉到跟腱的体积过渡构成，内外侧并非简单镜像 | 检查膝—腿肚—踝的连接和体积；具体夸张程度以当前二次元参考为准 |

二次元风格允许长腿、纤细四肢和比例夸张。复核同时看“是否符合参考图的风格与投影”和“关节、体积是否自洽”，不套用统一头身比，也不把风格化角色擅自改成写实人体。

## 3. 阶段定义：完整草稿之后还有清线

外层八个阶段保持不变：

1. 完整线稿。
2. 头发大色块。
3. 皮肤底色。
4. 服装大色块。
5. 配饰／鞋履底色。
6. 覆盖阴影。
7. 高光与整理。
8. 局部复核。

第 1 阶段内部细分如下。表中的标识是计划中的状态定义，不是当前已经开放的 WebMCP 参数。

| 子阶段 | 工作内容 | 允许保留的问题 | 进入下一步的条件 |
| --- | --- | --- | --- |
| 1A 整体定位 `layout` | 确定姿态、重心、头身、主要关节和物体占位 | 辅助线、简化体块、开放轮廓 | 全身大形具备一致的比例依据 |
| 1B 完整粗稿 `rough` | 按物体画大轮廓与主要结构，每个小部分画后复核 | 多次试探线、粗糙接头、未解决的小细节 | 全身结构均被考虑，不能遗漏四肢或用衣物掩盖未判断的体积 |
| 1C 结构修稿与全身复核 `structure_review` | 比较轮廓、比例、负形和透视，修正大形 | 线条尚不精致，但主要形状应明确 | 没有未解决的关键形态错误；有问题则回到 1A／1B |
| 1D 细化草稿 `refine` | 解决五官、手指、发束、衣褶及复杂交接，明确每根线的作用 | 少量待清理试探线 | 清线所需的形体和连接关系可判断；有歧义先观察或修稿 |
| 1E 精细清线 `clean` | 在独立清线层选择、重画和加工线条，每个小部分清完再复核 | 工作中的清线可以返修 | 轮廓、内部结构、连接与轻重达到目标，不能只因画遍全身便宣布完成 |
| 1F 清线后的整体复核 `lineart_review` | 隐藏草稿与全部参考，审视最终纯线稿；随后再与参考对照 | 仅允许明确接受的风格化取舍 | 比例、形体、遮挡、线条质量共同通过；失败回到对应步骤 |

存在两次独立的整体复核：**完整草稿后的结构复核，以及精细清线后的最终复核**。清线中发现形体错误，应返回结构阶段。复核不依赖用户再次批准才能继续；模型依据实际观察完成必要修正。

当前 `dist/lineart-study.line.json` 的 321 条记录中，9 条为辅助定位、312 条为可见笔迹。按本规范，它是**待修正的第一轮结构草稿**，不能视为第 1 阶段已经验收。原有图层名或历史文件名中的“ink／lineart”不构成质量认证。

## 4. 每个物体也要从大形到细节

先在全身布局中确定物体的大致位置和体积，再进入该物体的局部绘制。避免先精雕一只眼睛，最后才发现整个头或身体比例错误。

每个物体遵循以下循环：

1. **定大形**：确认占位、朝向、长宽关系和中心轴，必要时用简化体块或辅助线定位。
2. **画粗轮廓**：用能表达形体走势的笔触搭建外形，允许调整、重复和留口。
3. **即时检查**：对照参考检查形状，并连同相邻物体一起看。先修大形，再继续内部细节。
4. **补内部结构**：加入有实际作用的五官、指节、衣褶或发束线，并判断连接和遮挡。
5. **再次检查与记录**：说明哪里正确、哪里有偏差、修改了哪些笔迹，修后重新查看结果。

“一个小部分”按结构意义划分，例如一只眼睛、掌部与两根相邻手指、一段小腿或一个发束交叉处。不是机械地每一笔都做长报告，也不能把整个人物当作一个小部分，直到结束才检查。

粗稿的容错只针对线条表现和暂未确定的细节。明显错误的关节位置、物体宽度或遮挡判断，发现后仍需及时修正。

## 5. 局部复核：检查形状和空间关系

每次局部复核至少查看“当前对象＋相邻接触／遮挡对象”。仅裁出一根孤立曲线，无法判断它是否属于正确的形体。

| 维度 | 必须回答的问题 |
| --- | --- |
| 位置 | 这个部位相对于父对象、关节和邻近物体是否放对位置？ |
| 比例 | 长度、宽度及转折位置是否符合参考？有没有只凭印象把局部画窄、画长？ |
| 体积 | 两侧轮廓是否共同表达合理体积？近远侧、弯曲方向和透视是否一致？ |
| 结构 | 关节、指节、衣褶受力点、发束走向是否连贯？ |
| 遮挡 | 哪段在前、哪段在后？线条该连续、接触还是中断？ |
| 负形 | 手与脸之间、两腿之间、发束与袖子之间的空白形状是否接近参考？ |
| 线条 | 草稿阶段检查大方向；细化与清线阶段增加闭合、接头、重线和线宽检查 |

查看原始彩图和提取线稿时保持相同裁切与比例。放大用于看细节，同时保留父对象或整图缩略图，避免局部观察丢失尺度。

## 6. 整体复核与小腿错误案例

在 1C 和 1F 都检查下列项目：

- 全身剪影、姿态、重心与参考是否一致。
- 头、胸廓、骨盆的比例和朝向是否协调；肩、肘、腕、髋、膝、踝的位置是否成立。
- 四肢长度、粗细和体积过渡是否符合参考中的二次元风格。
- 两腿间距、手臂与躯干之间的负形、头发与服装外轮廓是否对应。
- 是否误将头发、尾巴、衣物边缘当成人体边缘。
- 隐藏草稿后是否丢失重要形体；清线是否改变了草稿中已经正确的神态或体积。

观察至少包含整图、重点局部和水平翻转视图。对照时参考与画布一起翻转，文档坐标不因此改变。翻转辅助发现偏差，不要求原图本就不对称的结构变成镜像。

### 回归案例：画面左侧小腿过细

用户已指出上一轮小腿过细。后续记录明确使用“画面左侧”，避免与角色自身的解剖学左右混淆。该问题视为尚待修正，不能靠重新命名为草稿而算作解决。

复查方法：

1. 在参考与草稿中分别由模型标出膝、踝和小腿最丰满处，确认两条边界确实属于小腿。
2. 对比膝到踝的投影长度、膝下宽度、腿肚最大宽度、变窄位置和踝部宽度。可对模型标注的点进行比例计算；测量为诊断依据，不自动驱动轮廓拟合。
3. 检查内外轮廓是否过早收窄，是否把肌肉到踝部的过渡简化成两条近乎平行的窄线。
4. 结合股部、鞋口、另一条腿和两腿之间的空白一起看；考虑腿的转向及透视，不能直接复制另一条腿或统一向两边加宽。
5. 先修正草稿中的体积，再清线；保存同尺度修前／修后局部，并退回全身复核。

人体知识用于检查结构自洽；本次临摹的形状和风格依据仍是用户提供的参考。不要套用固定的肌肉尺寸或头身比作为二次元角色的硬性标准。

## 7. 清线是一道独立加工工序

保留粗稿，必要时先形成细化草稿；降低其显示透明度，在各对象的独立清线层上选择或重画正式线条。保留正确曲线并局部修改也可以，不要求每根线都全部推倒重画。

清线至少处理六类工作：

1. **选线与修形**：在试探线中确定真正的轮廓，重新设计不准确的弧度和转折。不能把粗稿所有线一并描深。
2. **去除冗余**：清除辅助线、无意义的重复边、误穿插和装饰性碎线。
3. **连接与闭合**：该连续处连贯，该闭合的区域边界闭合；遮挡处截断，衣褶和发束内部线允许有意开放。
4. **线条轻重**：根据角色风格、体积、材质、遮挡与视觉重点设计宽度和压力。不能统一把外轮廓加粗，或只给所有笔迹套同一种两端变细。
5. **曲线节奏**：保持平顺的长走势，在自然结构转折处分笔；连续不等于整件物体必须一笔到底。避免密集短线、突兀接头与过度圆滑造成的玩具感。
6. **局部回看**：每清完一个结构，确认新线条保留了已经校准的大形；清线结束再执行全身复核。

统一平滑、提高清晰度或减小笔宽只能辅助运笔，不能代替上述加工。是否达到商业插画所需的精细程度，以实际纯线稿检视为准，不能用“经过清线步骤”自行认证。

## 8. 物体、区域、图层与线端关系

每个对象保存身份、父对象、位置／局部坐标、关键点、轮廓、材质、当前绘画成熟度和待复核问题。物体识别及关系由模型判断，工程保存可修改的判断，不把标签当作已经理解正确的证明。

| 关系 | 处理原则 |
| --- | --- |
| 物体前后 | 记录局部遮挡；同一发束穿插到不同深度时可拆为片段 |
| 边界连续 | 共用连接点；该平顺处保持切线关系，该转折处保留尖角 |
| 接触 | 接触点可以重合，但两个物体仍有各自身份和边界归属 |
| 区域闭合 | 颜色区域采用完整边界；其中被遮挡的闭合部分不必画成可见线 |
| 有意开放 | 衣褶、发丝内部线、受光留口需记录作用，避免错误自动闭合 |
| 透明部件 | 镜框与镜片分别处理；透明镜片不能按不透明前景遮掉眼睛 |

草稿阶段连接关系可以暂定并留待修正，不能用清线的精度要求阻止起稿。细化与清线阶段再解决未说明的线头、连接错误和区域漏口。端点靠近只能触发检查，不能不分对象地自动吸附。

对象内可以有草稿、底色、阴影、高光和清线层；层叠顺序由前后关系决定，绘画阶段控制操作时间。纯线稿时也需要模型定义的不可见遮挡区域，避免未上色的前景物体让后方线条穿透。

几何实现可借鉴[共享节点与边的矢量图形结构](https://www.borisdalstein.com/research/vgc/)。在 v4 中保留稳定笔迹 ID，新增曲线与边界关联，不要求迁移到其他绘画软件。

## 9. 参考线稿与辅助运笔

参考区显示原始彩图、提取线稿和当前画布的对应区域。提取前保留原图，维持长宽比与坐标变换；透明背景明确处理。提取线稿可能漏线、产生伪边或混入阴影边界，模型须回看彩图判断。

[Anime2Sketch](https://github.com/Mukosame/Anime2Sketch) 是待验证候选，当前尚未在本项目接入或确定其对这张参考的实际质量。先验证观察收益，再接成参考准备能力。参考图数据不作为自动生成画布几何的输入。

模型可以给出曲线需经过的位置，程序拟合连续曲线，并保留尖角、连接点和原始几何供后续修改。这类方法可参考 [SketchAgent](https://yael-vinker.github.io/sketch-agent/)。拟合输入来自模型提交的经过点，不来自自动提取的参考轮廓。

局部画布放大应从笔迹几何重新渲染；参考局部使用原图裁切。现有 `snapshot_region` 的放大是位图放大，不能当作已经具备高分辨率几何重绘。

## 10. v4 改进任务与状态

| 改进 | 当前状态 | 后续实现与验证 |
| --- | --- | --- |
| 草稿／细化／清线子阶段 | 目前仅有外层 `lineart` 阶段 | 增加子阶段与对象成熟度；草稿不能在第一根所谓清线开始时就被当作整体完成 |

| 经过点与曲线编辑 | 支持提交曲线，但归一化后主要保存采样点 | 保存原始曲线、连接点与压力信息，支持局部修改及相关边界联动 |
| 对应参考与整体观察 | 已有参考／画布局部快照与整图缩略图 | 增加提取线稿、同步翻转、父对象上下文和几何高分辨率重绘 |
| 阶段复核 | 已有文字复核记录，不会自动判定美术质量 | 增加局部／全身、草稿／清线的检查类型，记录问题、修订和复查结果 |
| 闭合与遮挡检查 | 有独立蒙版和剪贴层，没有完整端点关系 | 粗稿允许待定；清线检查未说明端点、错误连接与局部遮挡冲突 |
| 修改后的复核有效性 | 复核记录为历史文字 | 改动锚点、轮廓或遮挡后，将受影响局部及必要的整体复核标为待复查 |
| 图层性能 | 已有分层缓存与局部图层重画 | 保留缓存；新增几何关系只使受影响对象、邻接遮挡和局部缓存失效 |
| 绘画过程留存 | 已保存笔迹及修订原因，回放主要重放当前生效轨迹 | 保存粗稿／清线检查点及必要修订事件，区分最终笔迹回放与完整修改历史 |

这些任务是开发计划。本次文档更新不会让未实现接口立即可用，也不修改当前画布或参考图。

## 11. 复核记录模板

当前可在 `paint_record_review` 的 `note` 中按此模板记录；结构化字段待后续实现。模板填写必须来自实际查看，不用“已检查”代替观察内容。

```text
阶段：粗稿 / 结构修稿 / 细化草稿 / 清线 / 清线终审
范围：对象或画布区域；写明画面左右
查看内容：当前画布、同位置参考、必要的邻接结构或整图
观察：位置、比例、体积、遮挡是否成立；描述具体依据
问题：具体偏差或明确的有意开放线；没有把握处写待复核
动作：修改的锚点、对象或笔迹 ID，以及修改理由
修后复查：实际看到的变化及仍待解决的问题
结论：可继续 / 继续修正 / 回到大形；是否影响先前整体复核
```

关键大形问题未解决时，不能把对象标为清线完成。阶段检查通过只说明当时检查范围内的问题已处理，不保证模型判断绝对正确，也不替代用户对美术效果的评价。

## 12. 下一轮交付与执行摘要

下一轮先准备参考和全身布局，在完整草稿中优先检查两腿形体；随后用脸、扶镜手、附近刘海与袖口验证复杂空间关系和清线能力。局部实验不能绕过全身比例检查。

应保留可比较的产物：完整粗稿、结构修正后的草稿、局部清线样张、全身清线稿，以及两次整体复核记录。小腿问题另保留同尺度修前／修后局部。程序成功执行和艺术质量分别报告。

模型执行时遵循：

> 先看全身，再定物体。每个物体先画大形，粗稿允许试探；每完成一个小部分，检查它和邻接结构，发现大形错误立即修正。全身画满后将其视为完整草稿，检查姿态、比例、人体体积和临摹一致性。结构成立后再细化并独立清线，处理轮廓取舍、连接、闭合、遮挡和线条轻重。清线每完成一个局部再次检查；全部清线后隐藏草稿复核全身，通过后才进入颜色阶段。提取线稿只供观察，画布笔迹由模型组织与提交。
