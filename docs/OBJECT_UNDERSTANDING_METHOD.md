# 临摹中的全局物体理解方法

状态：方案稿。本文统一方法和术语，尚未替代正式绘画规范。正式规范仍维护在 [WORKFLOW_PRINCIPLES.md](WORKFLOW_PRINCIPLES.md) 与 `workflow-stages/`。

## 1. 目标

临摹不能只复制参考图中零散可见的线段。画者需要先理解画面中有哪些物体和身体部位、它们各自占据什么形状和位置、怎样连接、接触与遮挡，再用这些判断约束粗稿、细化和清线。

本方法同时控制注意力负担：完整识别集中在 1B 开始时完成一次；后续只取回当前对象的短说明、固定观察遮罩、参考局部和已有底稿，不反复加载全图分析或建立更细的遮罩。

## 2. 三个核心概念

### 2.1 全局物体图

全局物体图是模型在 1B 开始时，对整张参考图进行一次完整观察后形成的对象清单。它覆盖画面中所有主要可见身体部位、头发分组、衣物部件、配饰、道具，以及重要的开口、接触和遮挡关系。

每项对象记录回答：

1. 它是什么，或至少是什么几何形态；
2. 它由哪些主要部分构成；
3. 它与相邻对象怎样连接、接触或遮挡；
4. 哪些内容能够直接看见，哪些只是最低限度推断，哪些仍不确定；
5. 它在参考图中的可见形状和位置。

名称不明时可以使用“绕颈的窄带”“有开口的片状物”等几何描述，不要求猜准角色设定。

### 2.2 物体解释

物体解释是全局物体图中每个对象的简短构造判断。它不是三维模型，也不要求补画参考中不可见的完整结构。

建议使用一句话：

> `[对象]` 是 `[整体与主要部分]`；`[可见片段]` 通过 `[连接、接触或遮挡]` 属于同一结构；`[不确定部分]` 不凭空补画。

例如：

> 颈饰是一条绕颈的窄带；左右露出段属于同一物体，中段被前发遮挡；背侧扣合方式不可见，不补画。

### 2.3 观察遮罩

观察遮罩记录对象在原参考图中实际可见的形状和位置。它直接使用参考图坐标，由程序确定性地叠加显示，不通过图像生成工具重绘参考图。

遮罩遵守以下规则：

- 全局物体图中的每个主要对象对应一份固定遮罩；
- 同一物体被遮成多个可见片段时，一份遮罩可以包含多个不相连区域；
- 分组保持主要物件粒度，整只手、整条编发或整只袖子各自作为一个对象；
- 遮罩边界仍尽量贴合该对象在原图中的实际可见轮廓；“分组较粗”不等于轮廓可以粗糙；
- 1D 不再生成手指、指节、细发丝或衣褶等第二层遮罩；
- 后续只复用同一份遮罩，只有初次识别错误或漏掉可见区域时才纠正原记录。

遮罩属于观察数据，只用于识别、定位、裁图和检查归属。它不能自动转换为作品笔迹、上色范围、裁切蒙版或描图路径。

## 3. 人物作品的固定关注项

人物作品在 1B 全局检查中，默认检查参考中实际出现的以下部位：

| 部位 | 最低限度需要理解的关系 |
| --- | --- |
| 手 | 手腕、掌块、拇指、指组、朝向、叠压和接触 |
| 脚 | 脚踝、脚跟、足背、前掌，以及脚怎样进入鞋 |
| 关节 | 上下两段肢体怎样通过肘、膝、腕和踝连接 |
| 颈肩 | 脖子怎样连接躯干，衣领和头发怎样覆盖它 |
| 人体与衣物交界 | 手腕进入袖口、脚踝进入鞋口、身体从衣物后出现的位置 |

这是一份固定的短检查，不展开成人体教程。完全被遮挡、超出画面或与当前任务无关的部位直接标为不可见或跳过。

除固定人体项外，还要识别当前作品中特有的配饰、开口、带子、绳结、连接件、道具、复杂遮挡，以及同一物体分散露出的片段。

## 4. 粒度原则

全局物体图的粒度以“后续能够正确判断线条归属”为准：

- 手是一项对象；它的遮罩跟随可见手指形成的整体轮廓，但不为每根手指分别着色；
- 编发是一项对象；遮罩包含完整可见编发，不拆成每一节辫瓣；
- 袖子是一项对象；袖口可以在物体解释中说明，连续衣料上的明暗与褶面不建立独立对象；
- 裙摆可以按实际独立衣片分组，不把每个阴影三角形误认成部件；
- 颈带被头发隔开的左右露出段使用同一对象和同一份多区域遮罩。

清楚、连续的内部纹理、发丝和衣褶仍由后续看原图绘制，不需要加入全局物体图。

## 5. 1B 开始时的一次全局检查

开始 1B 后、提交完整粗稿前，当前作画模型完成一次全局检查：

1. 查看整张原参考图，确认构图和全部主要可见对象；
2. 按固定人体项与当前作品特有对象建立清单；
3. 为每项对象记录物体解释和观察遮罩；
4. 对同一物体的多个可见片段统一对象 ID；
5. 区分看见、最低限度推断与未知；
6. 将遮罩确定性地叠回原图检查，发现错分时当场纠正；
7. 完成后把整份全局物体图保存为后续阶段共同使用的观察依据。

这是由同一个作画模型完成的一次全局识别过程，不增加逐对象的其他模型确认。记录成功不等于视觉判断必然正确；后续发现矛盾时允许纠正同一份全局物体图。

## 6. 各阶段职责

| 阶段 | 物体理解职责 | 使用遮罩的方式 |
| --- | --- | --- |
| 1A 整体定位 | 建立姿态、人体大体块、头发和衣物大块的空间关系 | 不要求建立完整对象遮罩 |
| 1B 开始 | 一次识别全部主要对象和人体重点，建立全局物体图 | 为每项对象生成固定的可见观察遮罩 |
| 1B 作画 | 根据全局物体图完成主要体块、轮廓、连接和前后关系的粗稿 | 用固定遮罩确认对象位置与归属 |
| 1C 结构修稿 | 检查粗稿是否落实已经建立的构造、连接和遮挡判断，发现偏差就修稿 | 复用同一遮罩与原图，不逐项重新识别 |
| 1D 细化草稿 | 根据已修正粗稿展开手指、开口、厚度和局部叠压 | 仍复用 1B 遮罩，不新增细化遮罩 |
| 1E 独立清线 | 继承已成立结构并选择正式线条，不重新猜物体构造 | 用同一遮罩核对清线归属 |
| 1F 两轮审核 | 检查最终线稿是否保留物体归属、连续性、连接和遮挡 | 用同一遮罩定位待审对象，不增加审核轮次 |

1C 检查的是“粗稿有没有把既定理解画出来”，不重新承担一轮物体识别。如果发现全局物体图本身有误，则纠正对应记录，再继续修稿。

## 7. 后续局部绘画如何取回信息

画某个对象时，程序通过对象 ID 取回：

- 原参考图中该对象及其相邻环境的局部；
- 该对象的固定观察遮罩；
- 当前草稿和关联底稿笔迹；
- 简短的物体解释与未知项；
- 当前小批次需要解决的一个关系。

观察区域无需另存一套手工矩形。程序从遮罩外接范围自动向外增加留白，使裁图包含必要的遮挡物、连接部位和接触对象。少量连接、接触或遮挡端点可以作为辅助关键点保存，但不会形成新的遮罩层级。

例如细化颈带时，只返回：

> 同一条绕颈窄带，中段被前发遮挡；当前只检查遮挡两侧的带宽和走向。

随后对照原图局部、固定遮罩和当前草稿完成一小批修改。下一批仍使用同一物体记录，只更换当前关系。

## 8. 纠错与失效

- 普通绘画修改不会使观察遮罩失效，因为遮罩描述的是参考图，不是当前画布；
- 参考图、参考变换或画布坐标关系改变时，整份全局物体图失效，需要重新检查；
- 后续发现对象错分、漏分或多区域归属错误时，修订原对象记录并保留历史，不建立阶段专用的新遮罩；
- 新发现的对象补入同一份全局物体图，不在 1D 另建一套局部识别系统；
- 不确定处可以一直保留，直到参考提供足够证据。未确认的隐藏结构不补画。

## 9. 结果判断

全局物体图和后续画稿达到要求，需要同时满足：

- 主要可见区域都有明确对象归属；
- 同一对象的分散可见片段使用一致身份；
- 身体部位、衣物、头发和配饰不会因颜色或遮挡而相互混淆；
- 主要部件的连接、接触、开口和前后关系能够解释；
- 遮罩能准确找回原图位置，但没有被当作绘画轮廓直接转换；
- 1D 和 1E 不再需要重新决定“这是什么”或“这些可见段属于谁”；
- 最终关系能够从实际画面读出，而不是只能从文字记录得知。
