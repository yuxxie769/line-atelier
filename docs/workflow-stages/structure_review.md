# 1C 结构修稿

对照参考和完整粗稿，明确比例、方向、透视、关节、体积、轮廓曲率、负形及遮挡的偏差，再针对偏差修稿。局部改形影响相邻结构时连带修正。

进入本阶段后，先通过 `paint_get_reference_card` 完整读取必读的 CSP-03、CSP-04 与 CSP-07，之后才能提交或修改笔迹；它们分别用于上半身、下半身与复杂姿势拆解。该工具固定返回整章和全部说明图；CSP-08 可检查结构成立后的线条质量，CSP-09 可复查完整草稿链。卡片只作为构造与绘画指导，人物姿态、比例和设计仍以本次目标参考图为准。

尤其检查脚跟、足背、前掌组成的脚部体块，以及颈部与衣领、手腕与袖口的空间关系。不能只调整开口宽度而忽略整个物体的形状。

保留修订结果和未确定项。本阶段结束、推进到 1D 前，按程序返回的 `stage.agentReview` 开子 agent 初审，修订后新开子 agent 最终复核，最多两次。零明确 major 且材料充分可通过，minor 保留为建议。此为阶段协作复核；两轮正式审核仍统一在 1F。完整说明见 [子 agent 阶段复核](../workflow-actions/agent-review.md)。

每次只返修 1–3 笔，围绕一项已确认偏差调整。修改后立即对照原问题的曲率、宽窄、转向、接线或遮挡；检查仍为 `different`／`uncertain` 时继续处理当前问题，不能转去铺设无关笔迹。

从完整粗稿读取相关体块、方向线和轮廓依据，区分已经成立的结构与需要修正的偏差。保留有效定位，不把局部修稿变成整幅重新估形；修改后对照参考、粗稿及相邻部位复看。
