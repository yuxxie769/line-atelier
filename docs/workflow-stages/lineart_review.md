# 1F 两轮整体审核

子 agent **只介入第二轮清线审核**。第一轮仍由主 agent 按原流程执行；第二轮按程序返回的 `stage.agentReview` 先开子 agent 初审，修订后新开子 agent 最终复核，之后决定是否提交 lineart-checkpoint。两次子 agent 调用均属于第二轮内部，不重复第一轮、不新增第三轮；零明确 major 且材料充分可通过，minor 不单独阻断。完整说明见 [子 agent 阶段复核](../workflow-actions/agent-review.md)。

| 轮次 | 检查重点 | 必须回答的问题 |
| --- | --- | --- |
| 第一轮：结构与造型审核 | 透视、人体、体块、关节、遮挡，以及比例、轮廓、曲率、负形、整体美感 | 形体与连接成立吗？哪个在前？姿态是否合理？放回全身是否自然协调？关键角色特征是否保留？ |
| 第二轮：清线审核 | 边界、接头、线条轻重、重复线和杂线 | 每个物体是否读得清楚？有没有漏边、穿线、误接或仍未确定的草线？ |

两轮正式审核统一安排在 1F（lineart_review），不再在 1C 单独设置正式审核关卡。1A–1E 仍边画边观察和修正，每个局部完成后退回整体对照，但这些过程检查不另计审核轮次。

每轮都要结合参考图与实际渲染后的当前画布；整体审核还应查看缩小图和水平翻转图。第二轮使用缺口扫描与泄漏预览辅助判断。发现结构问题回到相应作画阶段修正，返回 1F 复查受影响项；不能为了凑轮数重复无关检查。

对鞋口与脚踝、袖口与手腕、领口与脖颈等跨物体交界，必须在局部对照中指出人体轮廓在哪里结束、开口的前后缘如何围绕体块、连接件附着在哪里。仅看到一条弧线或外轮廓闭合，不代表穿入和遮挡关系成立。参考图依靠颜色区分、但线稿中会混成同一区域的主要物体边界，需要明确画出；不能把这种缺边当作发丝或衣褶的开放收笔。

泄漏预览应针对待验交界选取一侧种子点和另一侧比较点，先按形体说明它们应当连通还是分开，再看实际结果；不能用衣身等其他部位的封闭结果替代鞋腿交界的验证。工具只能检查实际墨迹连通性，仍须目视确认边界位置、截面和厚度是否合理。两轮审核沿用原有安排，在对应轮次复核这些交界；记录具体观察与结果，不能用“鞋履已检查”等概括代替。

## 线稿的基本质量要求

| 维度 | 达标标准 |
| --- | --- |
| 人体与姿态 | 头、躯干、骨盆和四肢属于同一姿态；关节连接合理，双脚与承重关系成立 |
| 透视与体积 | 同一物体的方向、截面和厚度一致；袖口、鞋口等开口围绕对应体块 |
| 物体边界 | 不依赖颜色，也能辨认主要物体及其归属；可见外轮廓没有无依据的缺口 |
| 遮挡关系 | 前后关系明确；后方线条在正确位置消失，没有穿过前景物体 |
| 连接关系 | 肩接手臂、腕进入袖口、脚进入鞋内；连接处没有脱节、错位或不自然的收缩 |
| 线条完成度 | 已去除重复试探线、误线、毛刺和无意义碎线；长曲线流畅，尖角保留必要转折 |
| 线条层次 | 主轮廓、内部结构和细节有轻重区别；线宽变化服务于形体与遮挡 |
| 整体美感 | 缩小后轮廓清晰，比例协调，曲线有节奏，局部不会突兀地破坏整体 |
| 临摹一致性 | 保留参考图的姿态、主要比例、标志性轮廓和物体布局；合理修形不改变核心设计 |

## 程序提供的审核材料与核验

在 1F 调用 `paint_prepare_review`，重新取得核心原则、本阶段标准、整幅参考与当前线稿、镜像对照，以及按清线对象／部位／图层归组的局部对照和已登记问题区域。额外关注区域用 `regions` 指定。先独立找出形状、比例、体积、遮挡和精细度偏差，再处理 `pendingIssues`；材料不带入此前“已经正确”的审核结论。脚部须具体比较脚跟、足背、前掌；颈部须比较衣领开口、领结与相邻头发的细节和遮挡，不能用闭合或可辨认代替。

两轮正式通过都向 `paint_record_review` 提交实际返回的 `observationIds`。程序核验当前版本的整图、镜像和部位局部图片，且所有登记问题必须已处理并复查。只有 `evidence` 字符串、旧版本图片或编造的 ID 不能通过；图层显示、参考、几何、播放状态变化会使不对应的观察凭据失效。恢复工程／检查点后重新取图，导入的文字记录不能替代本次凭据。既有两轮顺序不变，不增加逐笔审批。

这些凭据只证明程序生成并返回了对照图片，不能证明模型实际理解了图片，也不自动判断美术质量。

## 线稿之后的推进

线稿通过后，按头发大色块 → 皮肤底色 → 服装大色块 → 配饰／鞋履底色 → 阴影覆盖 → 高光整理 → 局部复核推进。对象、图层前后关系和作画时间顺序分别管理；上色使用模型规划的连续宽笔与区域叠层，不用像素差值补丁掩盖线稿问题。用户只要求线稿时，停在线稿。

正式通过前还须完成 `localFeedback.inspection.pending` 的整图与部位检查记录。已有 observationIds 只代表图像材料；调用 `paint_record_inspection` 逐项写出参考形状、当前形状及结论后才具备检查过程证据。它不增加正式审核轮次，也不自动评判美术质量。
