# R2 回放等待修复

2026-09-05。绘画版本仍为 R2，448 条笔迹和七个检查点均保留。

## 原因

最终视图的 construction、rough、refine 图层隐藏，前 183 条笔迹仍占用播放时间。按原引擎每秒 180 个播放单位计算，可见清线之前约有 139 秒空白动画。初次准备和阶段切换还包含同步缓存重绘，因此此前容易误以为页面卡住。

## 修改

- 播放与下一笔跳过不可见笔迹的动画等待，仍完成缓存，保证之后显示图层时笔迹不丢失。
- 按对应时间位置判断图层可见性；只在未来清线开始时隐藏的构造层，起稿时仍正常播放。
- 全部图层隐藏时直接结束，不循环空放。
- 主回放与阶段回放显示准备状态，准备期间禁用重复点击，错误后恢复按钮。
- 时间轴仍保留整个工程的顺序和比例，因此 R2 正式清线回放从约 52% 开始。起稿在阶段查看器中观看。

## 验证

19 项引擎测试通过，覆盖隐藏草稿、缓存保留、自动隐藏时序、全隐藏终止、撤销、回放顺序及复核门槛。浏览器点击播放后，首次读取已经位于 r2-clean-neck-l，skippedPlaybackCommands 为 183；后续回放推进到 190 条，暂停与显示完成操作可用。还检查了人体阶段切换。

此次修复不修改绘画几何、清线审核或高清 PNG。
