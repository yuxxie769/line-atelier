# Line Atelier v4：视频观察与绘画方案改进

> 历史记录：本文描述早期参考图辅助重建实验，不是当前模型绘画执行规范。其中取色、自动分区和描摹生成画布几何的路线已停止使用。当前规范见仓库 `docs/DRAWING_WORKFLOW.md`；参考线稿提取现在仅允许用于观察。保留下文用于解释历史尝试，不将其陈述当作当前功能或质量验收结论。

参考视频：https://x.com/qibiz_me/status/2096074498403717530

这次观看到的是原帖的公开播放画面，并结合你最早提供的四张过程截图及作者回复截图分析。公开播放器在拖动进度和展开视频时弹出登录提示，因此没有逐帧检查全部内容，也没有获得未公开源码。下文区分直接观察与本版采用的实现方案。

## 视频里能看出的画法

| 环节 | 观察到的现象 | 对实现的启发 |
| --- | --- | --- |
| 画线 | 早期已有较完整的浅色轮廓，包含内部结构；原作者也形容过程接近打印机 | 可以预先分析参考图、组织连续轨迹，再逐段执行；不能据此认定模型临场逐笔构思 |
| 铺色 | 约 37.7 秒，头发主要是红色平面，皮肤与服装出现大块基础颜色 | 先建立完整色块与轮廓，再增加局部细节 |
| 塑形 | 中后段头发、脸部先变得细致，服装仍保留较粗的色块；约 75–80 秒能看到服装细化继续推进 | 顺序围绕部位展开，避免全画布随机寻找误差并打补丁 |
| 收尾 | 背景图形和文字在后段得到完善 | 主体与背景可以分开计划；阶段顺序应由任务决定 |
| 遮挡 | 后续细节建立在既有形状上，主体轮廓没有随宽笔铺色大面积失控 | 实现需要明确的覆盖关系、边界保护和可恢复的过程 |

右侧八项更像绘画阶段，不能据此断言程序内部有八个物理图层。视频也不能确认作者用了正片叠底、滤色、选区或特定 API；这些是本版为了重现上述行为而选择的实现。

你提供的作者回复称，原图是生成图片，草稿与配色涉及自动分析、描摹及笔刷重绘；作者同时表示其中一些解释来自 Astra 自己的说明。它提供了很有价值的线索，但不等于已审计的实现细节。

## 本版确实改了什么

- **整笔透明度**：先在临时笔迹表面绘制一整笔，再按一次透明度合入图层。重复经过同一点不会因为内部短线段反复累计透明度而出现深色结节。不同笔之间仍能叠色。
- **独立图层**：本次作品使用草稿、底色、阴影、亮部、五官配饰、线稿六层。阴影为正片叠底，亮部为滤色；上方色层可裁切到底色的透明度。
- **选区内运笔**：由参考图提取颜色区域的矢量边界，笔刷沿模型指定的形体方向运行，边界外不会落色。选区本身不产生可见色块，真正的颜色仍由 stroke 笔迹绘制。
- **先打底，再分块**：先用 181 笔覆盖角色轮廓的浅色打底，再铺主要色彩，减少相邻色块边缘留下的白缝。白色衣服是实际笔迹，不再被当作空白背景跳过。
- **分部位塑形**：先头部，再衣服、手部，再腿、鞋和尾巴。眼镜与鞋履使用小笔细化，最后在独立线稿层整理轮廓。
- **模型接口**：新增 paint_material_pass；paint_set_plan 支持混合模式、裁切关系和矢量选区，paint_submit 支持选区及笔压范围。JSON 入口也能执行这些分阶段操作。
- **回放性能**：缓存有限数量的选区渲染结果，避免每一小段都重新裁切复杂轮廓；缓存只是渲染优化，工程保存的是矢量边界和笔迹。

本次先通过可见 JSON 入口建立工程，浏览器恢复 WebMCP 后，实际通过 WebMCP 执行后续铺色、塑形、细化、线稿及快照操作。

## 新作品与过程

- 文件：lineatelier-v4-20972-strokes.line.json
- 20,972 笔，55,882 个轨迹点，6 个图层，7 个绘画阶段，185 个选区。
- 全部可见绘画指令都是 stroke；不包含 fill 指令、参考图像字节或成图揭幕动画。
- 草稿沿用此前编排的 79 条连贯轮廓；这次新增了分层色彩过程及 64 笔轮廓整理与发束、衣褶细线。不是宣称所有草稿都重新设计了一遍。
- GIF 是从网页实际渲染器按进度采样的两笔局部回放：一笔轮廓线、一笔头发铺色。它不是整幅绘画的实时录屏。

在网页中点击“载入 v4 分层绘画”。1× 适合看单笔，40× 适合浏览全程；“下一笔”固定按 1× 画完一笔。点击阶段可定位到该阶段起点；图层可独立开关。页面中的笔尖标记跟随执行坐标，不是系统鼠标。

## 仍然存在的边界

这仍是参考图辅助重建：模型安排形体方向、阶段和局部处理，程序承担取色、色块边界分析及大量路径生成。它不等于模型完全脱离原图像人一样临场创作，也不能证明原作者采用了相同算法。

选区裁切可能把一条连续路径的可见部分分成几个短段，细节仍有自动描摹和颜色量化的痕迹；最终画面不是原图的无损复制。要进一步减少这些特征，需要更少而更有语义的色块，以及对细线进行专门的结构化描摹。

验证包含 16 项回归检查及浏览器实际像素检查：整笔半透明叠加、选区孔洞、轮廓外留白、阴影叠加、逐段回放和工程导出。
