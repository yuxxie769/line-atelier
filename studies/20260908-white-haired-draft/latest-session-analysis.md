从报告文件时间和相邻调用估算，1A、1C、1F 的六次子 agent 审核大约消耗 15–16 分钟。这个数字只能作为编排成本估计，因为子 agent dispatch 没有写入绘画日志。它约占总耗时一成，且承担关键阶段独立复核；相比之下，1D/1E 的重复检查与 issue 更新更值得先优化。

本次平均产出速度为每分钟 1.32 笔，或每 2 分 16 秒完成一批三笔。若保持现有质量门禁，优先做三项调整：

1. 每批只检查实际改变的 target；整图和其他未变化 target 留到阶段检查点。1E 当前平均每批写 3.07 份检查记录，目标可降到约 1–1.5 份。
2. issue 只在相关笔迹被修改、相关图片更新或阶段最终复核时重新 resolve；不要在每个无关批次后重复处理历史问题。
3. 对低风险、连续且已确认结构的清线允许 5–6 笔一批；遮挡交界、五官、手脚仍维持 1–3 笔。

只消除多余检查记录和重复 resolve，按本次调用间隔估算可减少约 20–30 分钟；再采用风险分级批量，整段流程有机会从约 148 分钟降到 90–110 分钟。这个区间是基于本次单样本的工程估计，需要下一次绘画用同样日志口径验证。

## 各阶段主要考量

1A 关注头、胸廓、骨盆、肢体链和负形。两份子 agent 报告都认为坐姿、托腮手、下垂手和交叉双腿方向成立；左下足块偏窄、鞋底略高被列为 minor，内部连接受衣物遮挡被列为 uncertain。初审后没有改画，最终复核仍按同一 revision 7 通过。

1B 主要展开头发、服装和人体可见体积。日志显示每 3 笔后大量复看身体、头发和服装，但没有产生返修，也没有正式阶段审核记录。

1C 集中检查结构、体积、连接、遮挡和角色特征。实际修复了水手领内斜边；鞋体转面简略、抬袖体积略窄仍作为 minor 留给细化阶段。初审 revision 19，修后最终复核 revision 20。

1D 细化五官、手、发束、衣褶、鞋和丝袜破口。两次返修分别处理眼睛从占位到正式结构，以及腿线穿过丝袜破口。阶段正式记录认为主要细节已建立，仍保留抬袖饱满度和草稿线简化。

1E 关注正式线条的选择、遮挡起止、重复线和断口。四次返修都集中在边界语义：颈线被手遮挡、鞋带与鞋面重复、脸颊悬空起点、发尾与袖边无依据断口。虽然阶段规范还要求主轮廓、内部结构和细节有轻重区别，但日志没有把线重单一登记成待修问题。

1F 第一轮由主 agent 做结构检查，第二轮由两个子 agent 独立审核。缺口扫描得到 gap 61、dangling 20，但审核认为多为发丝、五官和衣褶的合理开放端；鞋踝、袖腕、颈领三组泄漏预览均符合预期的分隔关系。两名审核者都指出内褶接近外轮廓线重、右下衣摆折返偏尖硬、鞋口 V 偏尖、丝袜小破口简化；这些被判为 minor。第二轮初审和最终复核都绑定 revision 76，中间没有修改。

## 流程中暴露的问题

检查门槛生效了。10 次失败调用中，前期多次提交因为缺少当前版本的图像对照记录而被程序拒绝；另有问题未复核、审核材料不全和单条 path 含多次落笔等格式错误。这说明“仅取图不能放行”的硬门禁确实工作。

但检查质量没有被硬门禁验证。198 份检查、594 条陈述全部 `aligned`，与最终审核明确保留的多项 minor 不完全匹配。`aligned` 在规范中只表示达到阶段容差，并非完全一致，但连续 594/594 的结果仍说明模型倾向于把观察写成放行凭据，没有稳定地区分“可通过”和“值得马上修”。

问题跟踪也有明显噪声。日志只有 2 个实际问题：水手领内斜边和丝袜破口穿线，却执行了 92 次成功的 resolve；这些调用反复处理同两个历史 issue，并不代表检查出了 92 个问题或做了 92 次修改。

现行审核阈值偏向结构安全：零个有充分证据的 major 即通过，minor 不阻断。这适合避免因轻微风格差异反复返工，但不能保证线条表现达到“有选择、有主次、有粗细控制”的目标。要改善这类结果，应把 1E/1F 的线条层次从普通 minor 建议提升为明确验收维度，例如分别检查外轮廓、遮挡边、内部结构线和装饰线的相对线重，并要求至少指出若干具体线段的保留、减轻或重画决策；否则检查次数增加，画面也可能不变。
