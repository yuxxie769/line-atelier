# 膝盖局部折向试画

用户授权先试“重新设计每段轮廓”，并明确希望接笔保留细微折向、凸起，而非把所有转弯磨圆。本次承接上一轮离线对照试验，使用现有 `app/model.js` 与 `app/renderer.js`；没有修改应用源码、原作品或绘画规范，也没有填写网页绘画循环或正式验收通过记录。

## 实际改动

- 原始作品：`../20260908-white-haired-draft/1F-lineart.line.json`，600 × 849，revision 76，198 条命令。
- 原近腿轮廓 `ink-near-leg` 换成三条独立命令：大腿至膝前、膝部回转、膝下至小腿（此笔之后保留原足踝及内侧几何）。新路径不是旧路径的机械切分。
- 两个共用接点为 `(163, 527)`、`(171, 566)`，位置连续，但前后方向不完全一致；高密度采样测得折向约 11.51°、6.44°。
- 本次使用 `joinStyle: shared`，是共用端点接续，**没有做搭接、随机扰动或新增笔刷算法**。`smoothing: 0`，现有圆头笔刷仍会在笔宽尺度内自然圆化。
- 对照中旧、新轮廓均采用 1.5 px 等宽不透明线。导出的独立候选也采用此等宽控制，因此整条被替换轮廓的压力不同于原稿；不可把候选解释成局部外完全逐像素不变的正式修图。
- 其余 197 条命令保持一致；原轮廓 `(290, 644)` 后的路径文本保持一致。原文件字节未改。

## 看图后的判断

修改前后实际查看了参考裁切、画稿局部、旧细化稿以及候选整图。旧细化稿沿用了 rough 层的 `leg-near-visible`，不能只取 refine 子阶段当作完整底稿。

参考显示膝部回转后向右下接入小腿；旧稿外缘比较匀圆，小腿边缘较直。新版在膝前增加稍直的小段，膝下有小幅折向，放大图接点没有明显断缝、分叉或尖刺。整体仍连续，变化克制。参考仅 600 × 849，不能据此断言参考中存在相同的每个微折角；这些是用户要求下的风格化试探。

局限：内侧膝弯的硬 V 形、整体形体简化仍在，没有修复这些问题。本次几何和接笔位置同时改变，没有单独隔离“转向角度”的视觉贡献，也没有证据证明三个笔段比其他数量更优。结论仅是验证局部非平滑接续可以保留下来，不是“已达到人类线稿质量”。
